# Відстежувані твори і зовнішня бібліографія (OL → GB, Libex-міст)

## Контекст

Гриль 2026-09-16 («book tracker»: куток прослуханого для творів, яких немає
в джерелах) протиставив три знайдені варіанти домену: Work живе без Source,
а зовнішня база дає лише Work-рівень Metadata Assertions, ніколи не доказ
аудіо. Живі проби трьох дослідників: book-filter — без API й ліцензії, лише
англомовне; Goodreads-датасет — мертвий з 2021, гігабайти, DMCA-ризик, без
обкладинок; Open Library — ~100 тис. `language:ukr` works, найчистіша
ліцензія; Google Books — часткове укр-покриття за ISBN, без ключа 429,
аудіо-полів немає; Audnexus — лише збагачення за відомим ASIN, укр-аудіо
як discovery непридатний (регіону UA немає). Доперевірка: Libex
(LibexHQ/Libex, MIT, публічний `libexdb.com`, keyless, Docker-self-host,
AudiMeta-сумісний) підтверджена живцем — пошук за назвою працює
(`/search?title=`), укр-покриття доведено («Кобзар» → B0CVQDFRB5,
українська, 914 хв, диктор Руслан Драпалюк); запасний міст назва→ASIN —
прямий Audible catalog API без ключа (перевірено, включно з «Кобзарем»).
Hardcover — лише з ключем (безкоштовний PAT, Free 5000/день), кандидат на
v2; Bindery — не знайдено, потрібен лінк.

## Рішення

1. **Куток = Відстежуваний твір.** Library Entry над Work без Source, чесний
   стан «аудіо недоступне»; ручне створення — назва + автор (mergeKey),
   обкладинка ззовні, правки як Metadata Override; лише прослухане, текст
   поза каталогом за чинним рішенням.
2. **Ланцюжок бібліографії: Open Library primary, Google Books fallback за
   ISBN.** book-filter і Goodreads-датасет відхилено; аудіо-поля у v1 ззовні
   не тягнемо.
3. **Libex — місток назва→ASIN (закладка на v2, без коду в v1).** Keyless
   `libexdb.com` (MIT, Docker-self-host за бажанням) як кандидат №1 для
   майбутнього збагачення (диктор, тривалість, розділи) плюс прямий Audible
   catalog API як запасний міст; Hardcover — кандидат на v2 (потрібен
   акаунт+токен).
4. **Без грошей і без homelab у v1.** Куток — локальна Room як звичайна
   Медіатека, синк існуючим механізмом за Recovery Code; зовнішні відповіді
   кешуємо локально по ISBN/Work-ключу крізь Source Request Gate, GB-ключ
   ховаємо за Web Transport.
5. **Поява аудіо — підсвітити, не імпортувати.** Source Watch і мапування за
   MergeKey, тап імпортує звичайними дверима; ручна позначка «Прослухано» —
   той самий прапорець завершення.

## Наслідки

- Твір без аудіо не плодить другої сутності й не ламає аксіому «Дзеркало
  ніколи не джерело істини».
- Жодного бандл-дампа в APK, жодного ключа в клієнті, жодного серверного
  конвертера чи хостингу аудіо.
- Дірка укр-сучасності в Open Library закривається ручним створенням і
  краудсорсом, а не скрапом.
