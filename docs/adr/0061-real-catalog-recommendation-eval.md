# Історичне посилання на перевірку рекомендацій

- Статус: історичне посилання; це не окреме архітектурне рішення.

Рішення про перевірку рекомендацій перенумерував у [ADR-0062](0062-real-catalog-recommendation-eval.md). Його правила, пороги й результати не змінював.

У гілці #487 це рішення спочатку мало номер 0061. Номер 0061 залишаю окремому рішенню про локальну теку за посиланням (#1185). Старі згадки ADR-0061 у замороженій специфікації та архівах рекомендацій стосуються саме [ADR-0062](0062-real-catalog-recommendation-eval.md).

Цей шлях лишаю для тих незмінних посилань. Префікс `0061-` у назві файла зберігає історичну адресу, а не номер ще одного чинного ADR. Специфікацію, архіви й реєстри входів не переписую.

## Експеримент recording-text-v4: службовий текст запису

[Правила й межі очищення службового тексту](0062-real-catalog-recommendation-eval.md#експеримент-recording-text-v4-службовий-текст-запису) перенесені разом із рішенням. Цей заголовок зберігає старе посилання з архіву v4.
