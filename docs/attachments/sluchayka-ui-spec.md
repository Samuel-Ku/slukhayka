# Слухайка — UI-специфікація та аудит інтерфейсу

> Документ фіксує поточну структуру інтерфейсу за скриншотами: три головні вкладки, розташування об'єктів, ієрархію шарів, дизайн-токени, а також аудит неузгодженостей і план наведення ладу.
> Усі розміри й кольори наближені (знято зі скриншотів 1080×2400) — перед імплементацією зафіксуй їх як дизайн-токени в коді.

---

## 1. Навігаційна модель

### 1.1. Дерево екранів

```
Root (BottomNavHost)
├── Вкладка 1 · Слухати
│   └──→ BookDetails → NowPlaying
├── Вкладка 2 · Огляд
│   ├──→ ТОП 100 / Виконавці / Автори
│   ├──→ Список за жанром
│   ├──→ BookDetails → CyclePage («Епоха божевілля»)
│   └──→ SearchScreen (іконка 🔍 в AppBar)
├── Вкладка 3 · Медіатека
│   ├──→ BookDetails (sub-tabs: Chapters / Bookmarks)
│   ├──→ Закладки · Статистика (sub-tabs)
│   └──→ AddAudioFlow / FolderPicker (SAF)
└── Глобальні модальні шари (поза вкладками)
    ├── NowPlaying (full-screen modal)
    └── ChaptersBottomSheet
```

### 1.2. Z-ієрархія шарів

| Шар | Компонент | Правило |
|---|---|---|
| 0 | Контент активної вкладки | Скролиться під усіма шарами |
| 1 | BottomNav | Закріплена, видима на всіх кореневих екранах |
| 2 | MiniPlayer | Плаваюча картка над BottomNav; схована, доки немає сесії відтворення |
| 3 | Push-екрани (BookDetails, CyclePage) | Покривають контент вкладки; BottomNav + MiniPlayer лишаються |
| 4 | NowPlaying | Модалка на весь екран; відкривається тапом по MiniPlayer, закривається swipe-down або ⌄ |
| 5 | BottomSheet (Розділи), діалоги | Поверх усього, зі скримом |

**Ключовий принцип:** відтворення — глобальний стан (PlaybackService / MediaSession), тому MiniPlayer і NowPlaying живуть поза графом вкладок і не скидаються при навігації. Це пряма реалізація цілі «миттєве відновлення прослуховування».

## 2. Дизайн-токени

### 2.1. Кольори (≈ зі скриншотів)

| Токен | Hex ≈ | Використання |
|---|---|---|
| `bg/base` | `#0C0E13` | Фон усіх екранів |
| `bg/surface` | `#1A1D27` | Картки, чипи, міні-плеєр |
| `bg/surface-2` | `#242938` | Вкладені елементи, неактивні чипи, підложка активної вкладки |
| `accent/primary` | `#F0A437` | Активна вкладка, primary CTA, прогрес, поточний розділ |
| `accent/on-primary` | `#141414` | Текст/іконки на акцентній заливці |
| `accent/muted` | `#4A3B22` | Вторинні play-кнопки (зараз надто темний — див. аудит №7) |
| `text/primary` | `#F4F4F6` | Заголовки, назви книг |
| `text/secondary` | `#9AA1AD` | Автори, метадані, тривалість |
| `semantic/fav-danger` | `#E7A1A8` | ♥ обране, 🗑 видалення |
| `stroke/divider` | `#FFFFFF` 6–8% | Роздільники, обводки чипів |

**Правило семантики:** помаранчевий — тільки головна дія й активний стан; рожевий — тільки favorite/destructive. Не змішувати.

### 2.2. Типографіка

| Стиль | Розмір / вага ≈ | Де використовується |
|---|---|---|
| `display` | 30–32 sp Bold | Заголовки екранів («Медіатека», «Слухайка») |
| `section` | 20 sp Bold | «Щось коротке», «Розділи», «Що кажуть джерела» |
| `overline` | 12–13 sp Bold, CAPS, letterspacing | «КАТАЛОГ», «ЖАНРИ», «ПРОДОВЖИТИ СЛУХАТИ», «ЗАРАЗ ЗВУЧИТЬ» |
| `card-title` | 18–20 sp SemiBold | Назва книги в картці/списку |
| `body` | 15–16 sp Regular | Основний текст |
| `meta` | 13 sp Regular, `text/secondary` | Автор, тривалість, «Залишилось…» |

### 2.3. Геометрія

| Токен | Значення ≈ |
|---|---|
| Відступ екрана (padding) | 16 dp |
| Радіус картки | 16–20 dp |
| Радіус обкладинки: список / картка / плеєр | 12 / 16 / 24 dp |
| Радіус чипа | 12 dp |
| Висота BottomNav | 64–72 dp |
| MiniPlayer | висота 64 dp, бокові поля 8 dp, радіус 20 dp, піднятий на 8 dp над BottomNav |
| Мінімальний touch-target | 48×48 dp (критично для сценарію «за кермом») |
| Головна play-кнопка | 72 dp; у списках — 44–48 dp |

## 3. Глобальні компоненти

### 3.1. BottomNav

```
BottomNav (3 items: icon 24dp + label 12sp)
├── Слухати    (headphones)
├── Огляд      (compass)
└── Медіатека  (library / music-stack)
```

- Активна вкладка: іконка в овальній підложці `bg/surface-2` + акцентний колір іконки й лейбла.
- Неактивна: `text/secondary`, без підложки.
- Порядок вкладок = сценарій користувача: **продовжити → знайти нове → моє**. Це еволюція колишньої 2-вкладкової моделі «Головна / Медіатека»: «Огляд» винесено окремо, щоб розвантажити головну.

### 3.2. MiniPlayer

```
MiniPlayer (floating card, layer 2)
├── Cover 40dp (radius 8)
├── Column: Title (1 рядок, ellipsis) / «Глава N» (meta)
├── PauseButton (icon, accent)
├── NextButton (icon)
└── ProgressHairline — тонка акцентна смуга по верхньому краю картки
```

- Тап по картці → NowPlaying; кнопки мають окремі touch-зони й не пробуксовують тап наверх.
- Відома проблема: довгі назви ріжуться («Трохи ненависті - Ауд…») — див. аудит №8.

## 4. Вкладка «Слухати»

**Призначення:** повернення до прослуховування за один тап + швидкі рекомендації. Це «home» застосунку і головний носій UX-цілі «instant resume».

### 4.1. Дерево об'єктів

```
SluchatyScreen (vertical scroll)
├── Overline: «🎧 ПРОДОВЖИТИ СЛУХАТИ» (accent)
│   └── ContinueListeningCard (surface, radius 20, padding 16)
│       ├── Cover 80dp
│       ├── TextBlock: Title (card-title) / Author (meta)
│       │              «Розділ 11 із 65» / «0% · Залишилося 16 год 32 хв»
│       ├── PlayButton 56dp (accent, правий край, вертикальний центр)
│       ├── InfoButton 24dp (під play)
│       └── ProgressBar (full-width, 3dp, низ картки)
├── SectionHeader: «Щось коротке» + subtitle «менше години прослуховування» + ⋮
│   └── ShortListenRow ×N (surface, radius 16, height 72dp)
│       ├── Cover 56dp
│       ├── Title / Author [+ «Розділ 1 · 00:18», якщо вже слухав]
│       ├── PlayButton 44dp (accent/muted)
│       └── DismissButton «×» (прибирає рекомендацію)
└── [глобальний шар] MiniPlayer + BottomNav
```

### 4.2. Ієрархія уваги

1. **Картка «Продовжити»** — найбільша на екрані, єдина з акцентною кнопкою 56 dp. Очі й палець йдуть сюди першими.
2. **«Щось коротке»** — вторинна секція; кнопки навмисно приглушені, щоб не конкурувати з головною карткою.
3. **⋮ у заголовку секції** — третій рівень: налаштування/приховування рекомендацій.

**Логіка контенту:** фільтр «менше години прослуховування» — готовий сценарій «послухати в черзі/дорозі». Патерн варто зберегти й масштабувати: «Недослухане», «Закладки поруч», «Дослухати до кінця < 30 хв».

## 5. Вкладка «Огляд»

**Призначення:** каталог і дискавері. Три рівні звуження вибору: кураторські входи → жанри → повний каталог із сортуванням і фільтром.

### 5.1. Дерево об'єктів

```
OglyadScreen (vertical scroll)
├── AppBar: Logo «🎧 Слухайка»  |  ⟳ Refresh  |  🔍 Search
├── Overline «КАТАЛОГ»
│   └── ChipRow: [ТОП 100] [Виконавці] [Автори]        ← кураторські входи
├── Overline «ЖАНРИ»
│   └── ChipRow (horizontal scroll): [Казка] [Вірші] [Роман] [Жахи] [Драма] …
├── Overline «ВЕСЬ КАТАЛОГ»
│   ├── SortChips: [Спочатку нові *] [За назвою] [Усі джерела ▾]
│   ├── FilterChips (scroll): [Усі жанри *] [Казка] [Вірші] [Роман] …
│   └── BookListItem ×N (height 80dp)
│       ├── Cover 64dp (radius 12)
│       ├── Title (max 2 рядки) / Author (meta)
│       └── PlayArrow 24dp (accent, правий край)
└── [глобальний шар] MiniPlayer + BottomNav
```

### 5.2. Правила

- Чипи сортування/фільтра — **single-select**; активний чип: заливка `bg/surface-2` + акцентний текст/обводка.
- PlayArrow у рядку = «швидкий старт» без переходу в деталі; тап по рядку → BookDetails. Дві різні дії — дві окремі touch-зони.
- Порядок секцій фіксований: **кураторське → тематичне → повне**. Це воронка дискавері, не переставляти.
- Якщо повертатимешся до Netflix-стилю каталогу (горизонтальні полиці) — ця вкладка є природним місцем для нього: секції «КАТАЛОГ»/«ЖАНРИ» легко розгортаються в горизонтальні ряди обкладинок.

## 6. Вкладка «Медіатека»

**Призначення:** особиста колекція + контроль (пошук, фільтри, сховище, імпорт через SAF).

### 6.1. Дерево об'єктів

```
MediatekaScreen
├── Header: «Медіатека» (display) + subtitle «Всі книги в одному місці» (meta)
├── ActionRow: [⬆ Додати аудіо — PRIMARY, accent] [📁 Папку — outlined]
├── SubTabs: [Книги (63) *] [Закладки (1)] [Статистика]
│      активний = accent text + underline 3dp
├── SearchField: «Пошук у медіатеці…» (surface, radius 16, height 52dp)
├── FilterChips: [Усі *] [Слухаю] [Завершені] [Завантажені]
├── SortRow: «≡ Нещодавно слухані ▾» (accent)  ……  [grid/list toggle]
├── StorageRow: «Пам'ять пристрою: 0 МБ · 0 аудіокниг offline» + «Очистити» (danger-text)
└── LibraryBookCard ×N (surface, radius 16, padding 12–16)
    ├── Cover 72dp
    ├── Title / Author / Series «Епоха божевілля · Книга 1» (meta)
    ├── ProgressBar + «Залишилось 14 год 5 хв»
    └── SourceBadge («4read», «Sound-Books») — outlined chip, правий нижній кут
```

### 6.2. Порядок операцій над списком

```
усі книги → sub-tab (Книги) → пошук (query) → фільтр-чип (стан) → сортування → рендер
```

Зафіксуй цей ланцюжок у ViewModel: зі скриншотів неочевидно, чи комбінуються пошук із фільтром (мають комбінуватися, інакше це баг).

### 6.3. Ієрархія

1. **Primary-дія екрана — «Додати аудіо»**: єдина акцентна кнопка.
2. **Sub-tabs** — перемикачі контексту; лічильники в дужках.
3. **Пошук → фільтри → сортування**: чим нижче, тим тонше налаштування.
4. **StorageRow** — сервісна інформація, найслабший контраст; danger-дія «Очистити» винесена праворуч, подалі від primary.

## 7. Екран «Зараз звучить» (NowPlaying)

```
NowPlayingScreen (modal, layer 4)
├── TopBar: ⌄  |  «ЗАРАЗ ЗВУЧИТЬ» (overline)  |  ⋮
├── Cover (≈70% ширини, radius 24, center)
├── Title (display-small) / Author (body) / «Читає …» (meta)
├── CurrentChapter: «Глава 11» (accent, section-style)
├── ChapterProgress: label «Розділ» + «08:49 / 18:01» + Slider
├── BookProgress:    label «Книга»  + «2:35:41 / 16:41:11» + SegmentedSlider
├── TransportRow: ⏮  |  ↺15  |  ⏸ 72dp accent  |  30↻  |  ⏭
└── ActionRow (4× icon+label): Швидкість 1.0× | Таймер | Закладка | Розділи
```

**Патерн dual-progress** — сильна сторона екрана: шкала розділу дає мікроорієнтацію, сегментована шкала книги (сегменти = розділи) — візуальну карту всієї книги. Зберігай сегментацію.

«Розділи» відкриває sheet поверх плеєра:

```
ChaptersBottomSheet (layer 5)
├── Handle + Header «Розділи»
└── ChapterRow ×N: «Глава N»  ……  duration (meta, правий край)
```

## 8. Екран деталей книги (BookDetails)

Два стани одного екрана:

```
BookDetails
├── AppBar: ← | Title (1 рядок, ellipsis) | ♥ | ✎ | ⬇ | 🗑
├── Стан A «Інфо»
│   ├── Cover (large, radius 20, center)
│   ├── Title / «By {author}» (accent) / «Narrated by {…}» (meta)
│   ├── GenreChips: [Сучасна проза · Пригоди · Фентезі]
│   ├── MetaChips: [65 Ch. · 16:41:11] [★ 4.6] [4read.org Source]
│   ├── SeriesBadge: «Епоха божевілля» · Кн. 1   → CyclePage
│   ├── «Джерело: {filename}» (meta)
│   └── SourceCard «Що кажуть джерела»: badge 4read · ★ 4.6 · читає · опис
└── Стан B «Розділи»
    ├── ActionRow: [▶ Playing — PRIMARY] [Download ⬇] [🔖+]
    ├── SubTabs: [Chapters (65) *] [Bookmarks (1)]
    └── ChapterRow ×N: № (circle 40dp) | «Глава N» / «Duration: 20:05» | ▶ 44dp
```

**CyclePage** (приклад «Епоха божевілля»): AppBar ← + назва циклу; лічильник «N книг у циклі»; картка книги з жанрами (accent-text), тривалістю та play. Це реалізація групування за серіями/циклами з нашої колишньої концепції каталогу.

## 9. Принципи візуальної ієрархії (зведено)

- **Один акцент — одна дія.** На кожному екрані лише одна primary-кнопка в `accent/primary`.
- **Overline → Section → Content.** Кожна секція: капсовий підпис → жирний заголовок → картки.
- **Глибина тоном, не тінями.** `bg/base` < `surface` < `surface-2` < модалки зі скримом.
- **Акцентний текст замість заливок** для вторинного: жанри, сортування, «Глава 11».
- **Прогрес завжди акцентний** — це «жива» частина інтерфейсу, її видно навіть у темряві та периферійним зором (важливо для нічного сценарію).

## 11. Чек-лист наведення ладу

**P0 — сприйняття якості:**
- [ ] Локалізувати всі рядки UI українською (strings.xml / ресурси)
- [ ] Плюралізація лічильників (книг / розділів / закладок)
- [ ] Єдине джерело правди для прогресу на всіх екранах

**P1 — гігієна даних:**
- [ ] Нормалізатор назв книг при імпорті з джерел
- [ ] Валідація тривалості розділів
- [ ] Прибрати технічні імена файлів з UI

**P2 — полірування:**
- [ ] Контраст вторинних play-кнопок
- [ ] Поведінка довгих назв (marquee / 2 рядки)
- [ ] Семантична палітра іконок (accent / favorite / danger)
- [ ] Empty-стани: порожня медіатека, порожні закладки, немає мережі
- [ ] Accessibility: `contentDescription` для всіх іконок, touch-targets ≥ 48 dp, контраст тексту ≥ 4.5:1

---
