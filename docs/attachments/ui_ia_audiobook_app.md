# UI / IA: наведення ладу в аудіокнижковому застосунку

## Мета

Перетворити поточний інтерфейс на послідовну, зрозумілу систему з трьома головними вкладками:

1. **Слухати** — швидко продовжити або почати прослуховування.
2. **Огляд** — знайти нову книжку та дослідити каталог.
3. **Медіатека** — керувати власною колекцією, завантаженнями, закладками й статистикою.

Головний принцип: кожна вкладка повинна відповідати на **одне головне запитання** користувача.

| Вкладка | Головне запитання | Головна дія |
|---|---|---|
| Слухати | «Що я слухаю зараз?» | Продовжити відтворення |
| Огляд | «Що послухати далі?» | Відкрити або додати книжку |
| Медіатека | «Де мої книжки?» | Знайти, організувати або завантажити |

# 1. Глобальна навігація

## Нижня панель

Нижня навігація має бути незмінною на всіх основних екранах і містити рівно три пункти:

```text
[ 🎧 Слухати ]     [ 🧭 Огляд ]     [ ♫ Медіатека ]
```

### Правила

- Активний пункт: помаранчева іконка + помаранчевий текст + темний овальний фон.
- Неактивний: нейтральний світло-сірий колір.
- Іконка над підписом; текст не замінювати лише іконкою.
- Висота панелі: 88–96 dp плюс системний safe area.
- Панель не повинна зникати при переході між кореневими вкладками.
- На дочірніх екранах (деталі книжки, плеєр, цикл) вона може ховатися, якщо заважає задачі.

## Мініплеєр

Мініплеєр — глобальний об’єкт стану, а не частина конкретної вкладки.

```text
┌──────────────────────────────────────────────┐
│ [обкладинка]  Назва книги              [Ⅱ] [▶▌] │
│               Розділ 11                         │
│ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  │
└──────────────────────────────────────────────┘
```

### Поведінка

- Показується над нижньою навігацією тільки коли є активна або призупинена книжка.
- Натискання на весь блок відкриває повноекранний плеєр.
- Кнопка паузи/відтворення має окрему зону натискання.
- Прогрес — тонка лінія у верхній або нижній частині картки, без дублювання відсотків.
- Не показувати більше двох рядків метаданих: **назва** і **поточний розділ**.

## Візуальна ієрархія

У застосунку варто зафіксувати 4 рівні тексту:

| Рівень | Призначення | Приклад |
|---|---|---|
| H1 | Назва екрана | «Медіатека» |
| H2 | Назва секції | «Продовжити слухати» |
| Title | Назва книжки | «Трохи ненависті» |
| Meta | Автор, тривалість, статус | «Джо Аберкромбі · 16 год 41 хв» |

### Рекомендовані параметри

- H1: 32 sp, Semibold/Bold.
- H2: 22–24 sp, Semibold.
- Title: 18–20 sp, Semibold.
- Meta: 15–17 sp, Regular або Medium.
- Основний текст: теплий білий.
- Другорядний: приглушений сіро-бежевий.
- Акцент: помаранчевий — **лише для дій, активного стану, прогресу та важливих чисел**.

Не варто фарбувати помаранчевим усі заголовки, таби й кнопки одночасно: акцент перестає бути акцентом.

# 2. Вкладка «Слухати»

## Роль вкладки

Це домашній екран для регулярного користувача. Він не має бути каталогом або бібліотекою. Найважливіше — відновити прослуховування за один дотик.

## Ієрархія блоків

```text
Слухати                                      [оновити] [пошук]

┌─ ПРОДОВЖИТИ СЛУХАТИ ─────────────────────────────┐
│ [велика обкладинка]  Трохи ненависті              │
│                      Джо Аберкромбі               │
│                      Розділ 11 із 65              │
│                      Залишилось 14 год 05 хв      │
│                      ━━━━━━━━━━━━━━━━○            │
│                                      [▶]           │
└───────────────────────────────────────────────────┘

Нещодавно слухали                               Усі →
[горизонтальна стрічка книжок]

Короткі епізоди                                 Усі →
[горизонтальна стрічка]

На потім                                        Усі →
[горизонтальна стрічка]
```

## Перший екран: «Продовжити слухати»

Це єдина велика картка на екрані. Вона повинна займати приблизно 35–45% доступної висоти до першого скролу.

### Склад картки

- Обкладинка 112–128 dp, зліва.
- Назва — максимум два рядки.
- Автор — один рядок.
- Стан: `Розділ 11 із 65`.
- Один зрозумілий показник прогресу: `Залишилось 14 год 05 хв` **або** `14%`. Для аудіокниг кориснішим є час, що залишився.
- Прогрес-бар.
- Велика кругла кнопка Play справа.
- Маленька кнопка `i` не є пріоритетною; перенести її в деталі книжки або контекстне меню.

### Що прибрати

- Не показувати «0%», якщо прогрес насправді є.
- Не дублювати одночасно «Розділ», «відсоток», «залишилось», «прогрес бар» без ясної системи.
- Не змішувати на головному екрані «короткі епізоди», випадкові рекомендації й усі незавершені книжки в один безкінечний список.

## Другорядні секції

### Нещодавно слухали

- Горизонтальний список із 5–10 позицій.
- Картка: обкладинка, назва до двох рядків, автор до одного рядка.
- Не додавати в кожну картку окрему велику кнопку Play: натискання по картці відкриває деталі, а маленький Play може бути в оверлеї обкладинки при hover/long-press або як trailing action.

### Короткі епізоди

- Залишати лише книжки/оповідання з тривалістю до заданого порогу.
- Показати маленький підзаголовок: «До 1 години прослуховування».
- Кнопка `×` для приховування рекомендації виглядає надто агресивно. Краще контекстне меню `⋮` → «Не показувати».

### Порожній стан

Якщо немає активного прослуховування:

```text
[ілюстрація навушників]
Немає активної книжки
Відкрийте каталог і знайдіть наступну історію.
[ Перейти до огляду ]
```

# 3. Вкладка «Огляд»

## Роль вкладки

«Огляд» — це discovery: пошук, каталог, жанри, автори, добірки та нові надходження. Вона не повинна повторювати структуру медіатеки.

## Верхній блок

```text
Слухайка                                      [↻] [⌕]

[ Пошук книжок, авторів, серій…                ]

[ ТОП 100 ] [ Новинки ] [ Автори ] [ Виконавці ]

Жанри
[ Фентезі ] [ Роман ] [ Жахи ] [ Пригоди ] [ Усі жанри ]
```

### Важливе рішення

Пошук повинен бути помітним відразу, а не тільки іконкою. Якщо каталог великий, поле пошуку — первинна дія, тому воно має займати повну ширину під шапкою.

## Структура вмісту

```text
Для вас                                        Усі →
[карусель книжок]

Новинки                                        Усі →
[карусель книжок]

Популярне цього тижня                           Усі →
[вертикальний рейтинг 1–5]

За жанрами
[сітка компактних жанрових плиток]

Від авторів, яких ви слухали                    Усі →
[карусель]
```

## Каталоговий список

Коли користувач переходить у «Весь каталог», використовувати окремий екран, а не намагатися вмістити все на стартовому екрані.

```text
← Каталог                                      [фільтр] [сортування]

[ Пошук у каталозі… ]

[ Усі жанри ] [ Усі джерела ] [ Будь-яка тривалість ]

1. [обкладинка] Дорога до світанку
                Роберт Сальваторе
                Фентезі · 12 год 14 хв                    [▶]

2. [обкладинка] Визначний день для долі бронтозаврів
                Майкл Свонвік
                Оповідання · 1 год 32 хв                  [▶]
```

### Принципи списку

- На стартовому екрані не змішувати `ТОП 100`, виконавців, авторів, жанри, сортування та повний список без чіткої межі.
- Фільтри — на екрані каталогу, не в головній шапці вкладки.
- Для кожної позиції показувати лише суттєве: обкладинка, назва, автор, 1–2 метадані, дія.
- Плей у списку має запускати з першого розділу або продовжувати, якщо є прогрес. Це треба пояснити коротким станом: `Продовжити · Розділ 4`.

## Екран деталей книжки

Усі входи до книжки — з «Огляду», «Слухати» та «Медіатеки» — мають вести до одного спільного екрану деталей.

### Порядок об’єктів

```text
← Назва                                           [♥] [поділитися] [⋮]

                    [велика обкладинка]

Трохи ненависті
Джо Аберкромбі
Читає Рік САН4ЕЗ

[ Фентезі ] [ 65 розділів ] [ 16 год 41 хв ]

[ ▶ Продовжити слухати ]  [ Завантажити ]

Про книжку
Короткий опис у 3–5 рядків…                     Розгорнути

Розділи (65)                                    Усі →
[1. Глава 1 · 20:05]
[2. Глава 2]
[3. Глава 3 · 08:29]

Джерело та оцінка
[ 4read · ★ 4.6 ]
```

### Ключові зміни

- `Playing` не повинен бути локалізований частково: використовувати `Слухаю` або `Продовжити слухати`.
- `Download` → `Завантажити`; `Bookmarks` → `Закладки`; `Duration` → `Тривалість`; `Narrated by` → `Читає`.
- Не показувати технічний slug URL (`7810-dzho-aberkrombi-…html`) як основний текст. Замість нього: назва джерела, домен або кнопка «Відкрити джерело».
- Серія — клікабельний чип: `Епоха божевілля · Книга 1`.
- Обкладинка не має витісняти головну дію: кнопка «Продовжити слухати» повинна бути видимою без скролу.

# 4. Вкладка «Медіатека»

## Роль вкладки

Це робоча зона користувача: власні книжки, прогрес, завантаження, закладки та статистика. Тут важливі контроль і пошук, а не відкриття нового контенту.

## Верхня зона

```text
Медіатека                                      [додати аудіо] [створити папку]

[ Книжки (63) ]   [ Закладки (1) ]   [ Статистика ]

[ Пошук у медіатеці… ]

[ Усі ] [ Слухаю ] [ Незавершені ] [ Завершені ] [ Завантажені ]

Сортування: Нещодавно слухані                  [⌄]
```

### Чому така послідовність

1. Назва і первинні дії — додати файл або організувати папку.
2. Режим даних — книжки, закладки або статистика.
3. Пошук у власній колекції.
4. Статусні фільтри.
5. Сортування.
6. Список.

Це прибирає конкуренцію між вкладками, фільтрами й діями у верхній частині екрана.

## Список книжок

```text
┌──────────────────────────────────────────────────┐
│ [обкладинка] Трохи ненависті                      │
│              Джо Аберкромбі                       │
│              Епоха божевілля · Книга 1            │
│              ━━━━━━━━━━━━━━━━━━━━━━○              │
│              Залишилось 14 год 05 хв        [⋮]   │
└──────────────────────────────────────────────────┘
```

### Ієрархія картки

1. Назва.
2. Автор.
3. Серія — лише якщо є.
4. Прогрес або статус завантаження.
5. Контекстне меню `⋮`.

### Не варто

- Показувати джерело як великий badge на кожній картці: воно візуально конкурує з назвою. Залишити його в контекстному меню або як маленьке вторинне поле у деталях.
- Дублювати прогрес тонкою лінією і повним текстом, якщо картка дуже компактна. Для активних книжок залишити обидва; для завершених — замінити на стан `Завершено`.
- Виносити «Очистити» поруч із інформацією про пам’ять без уточнення. Краще: `Керувати завантаженнями` → окремий екран із розміром кожного файлу.

## Підвкладка «Закладки»

Закладки — не другий список книжок, а список точок повернення.

```text
Закладки (1)

[обкладинка] Трохи ненависті
             Розділ 11 · 08:49
             «Над Адуа зависочіли промислові труби…»
             Створено сьогодні                         [▶]
```

- Один дотик по картці запускає потрібний момент.
- Довге натискання або `⋮`: перейменувати, видалити, поділитися.
- Текстова цитата — максимум два рядки.

## Підвкладка «Статистика»

Візуально відокремити її від керування бібліотекою: це огляд, а не список.

```text
Статистика

Цього тижня
4 год 38 хв                         +18% до минулого тижня

[простий графік за 7 днів]

Цього місяця
- 2 книжки завершено
- 18 год 12 хв прослухано
- Улюблений жанр: фентезі
```

Не перевантажувати статистику декоративними картками: три-п’ять метрик достатньо.

# 5. Плеєр, розділи та взаємодія

## Повноекранний плеєр

Плеєр повинен бути режимом фокусування. На ньому не потрібна нижня навігація і не слід показувати надто багато контролів одночасно.

```text
⌄                    ЗАРАЗ ЗВУЧИТЬ                         [⋮]

                       [обкладинка]

Трохи ненависті
Джо Аберкромбі
Розділ 11

Розділ                         08:49 / 18:01
━━━━━━━━━━━━━━━━○━━━━━━━━━━━━━━

Книжка                         2:35:41 / 16:41:11
━━━━━━━━━━━━○━━━━━━━━━━━━━━━━━━

[попередній] [−15]      [ ПАУЗА ]      [+30] [наступний]

[ Швидкість ] [ Таймер ] [ Закладка ] [ Розділи ]
```

### Правила плеєра

- Основна кнопка play/pause найбільша і завжди по центру.
- Другий рівень: назад 15 секунд і вперед 30 секунд.
- Перехід між розділами — крайні кнопки, візуально слабші за seek-контроли.
- Два прогрес-бари виправдані, але їх потрібно чітко відрізнити підписами «Розділ» та «Книжка».
- Не використовувати для розділів надмірно багато вертикальних рисок: вони створюють візуальний шум. Краще точки-маркери або дискретні сегменти лише там, де це справді допомагає.

## Bottom sheet «Розділи»

Нижній sheet доречний для швидкої навігації, але повний список із 65 розділів краще відкривати на окремому екрані деталей.

### Швидкий sheet

- Показує поточний, попередній і наступні 5–8 розділів.
- Поточний розділ виділяється помаранчевим маркером та станом `Слухається`.
- Натискання по рядку переходить у відповідний розділ.
- Кнопка внизу: `Відкрити всі розділи`.

### Повний список

- Номер, назва, тривалість, стан прослуховування.
- Довгі назви не повинні ламати структуру: два рядки максимум, тривалість — праворуч.
- Порожня тривалість (`00:00`) повинна мати пояснення або не показуватися до завантаження метаданих.

## Стани та мікровзаємодії

| Стан | Відображення |
|---|---|
| Не почато | Кнопка `Слухати` |
| У процесі | `Продовжити · Розділ N`, прогрес-бар |
| Призупинено | Мініплеєр з кнопкою Play |
| Завантажується | Локальний прогрес + `Скасувати` |
| Завантажено | Іконка офлайн, без великого badge |
| Завершено | Галочка + `Прослухано` |

- Тап по книжці: деталі.
- Тап по Play: негайне відтворення.
- Long-press: контекстне меню.
- Видалення книжки або завантаження: підтвердження лише якщо дію неможливо легко скасувати.
- Після додавання закладки: короткий snackbar `Закладку додано` + дія `Скасувати`.

# 6. Компоненти та дизайн-система

## Відступи

Використовувати 8-pt grid:

- 8 dp — мінімальний внутрішній відступ.
- 12 dp — відступ між щільними елементами.
- 16 dp — базовий відступ картки та бокові поля екрана.
- 24 dp — між секціями.
- 32 dp — перед важливим новим блоком.

Зараз частина екранів виглядає щільною через поєднання великих карток, багатьох chip-елементів і близьких відступів. Більша вертикальна пауза між секціями зробить інтерфейс спокійнішим.

## Картки

Використовувати не більше трьох типів:

| Тип | Де застосовувати | Властивості |
|---|---|---|
| Hero card | «Продовжити слухати» | Велика, одна на екрані, головна дія |
| Book row | Медіатека, каталог, розділи | Компактна, однакова висота, без зайвих кнопок |
| Collection card | Горизонтальні добірки | Обкладинка + мінімум тексту |

Не створювати окрему стилістику картки для кожної секції. Консистентність цінніша за декоративну різноманітність.

## Кнопки

- **Primary:** залита помаранчева, одна головна дія на екран або картку.
- **Secondary:** контурна, для «Завантажити», «Додати аудіо», «Створити папку».
- **Tertiary:** текстова або іконка, для фільтрів, меню, «Усі →».
- Іконка без підпису допустима лише для загальновідомих дій: назад, пошук, меню, пауза, завантаження.

## Локалізація

На скриншотах змішані українська та англійська. Необхідно уніфікувати інтерфейс українською:

| Поточний варіант | Рекомендація |
|---|---|
| Playing | Слухаю / Відтворюється |
| Download | Завантажити |
| Chapters | Розділи |
| Bookmarks | Закладки |
| Duration | Тривалість |
| Narrated by | Читає |
| Source | Джерело |
| 65 Ch. | 65 розділів |

Назви розділів залишати мовою самого аудіофайлу, якщо їх отримано з джерела. Але системні тексти мають бути однією мовою.

## Колір і доступність

- Помаранчевий має відповідати контрасту для тексту на темному тлі; не використовувати його для дрібного тексту, якщо контраст недостатній.
- Вторинний сірий текст потрібно зробити трохи світлішим: на темному фоні він не повинен зливатися.
- Усі інтерактивні елементи — мінімум 44×44 dp.
- Стан не можна передавати лише кольором: наприклад, активну вкладку підтримувати і фоном, і текстом/іконкою.

# 7. Пріоритет реалізації

## P0 — найбільший ефект

1. Зафіксувати ролі вкладок: «Слухати» = продовження, «Огляд» = discovery, «Медіатека» = керування.
2. Переробити hero-картку «Продовжити слухати» та мініплеєр.
3. Уніфікувати локалізацію українською.
4. Створити один спільний екран деталей книжки.
5. Очистити картки від дубльованих прогресів, зайвих badge-ів і конкуруючих Play-кнопок.

## P1 — покращення навігації

1. Винести повний каталог в окремий екран із пошуком, фільтрами і сортуванням.
2. Зробити пошук у «Огляді» та «Медіатеці» контекстно різним.
3. Розділити короткий sheet розділів і повний список розділів.
4. Додати повноцінні стани: порожня бібліотека, завантаження, помилка джерела, завершена книжка.

## P2 — polish

1. Статистика прослуховування.
2. Папки/колекції у медіатеці.
3. Рекомендації на основі історії.
4. Тонкі анімації переходу mini player ↔ full player.

# 8. Короткий UX-чекліст

Перед релізом перевірити кожен екран:

- Чи зрозуміло за 2 секунди, яка головна дія?
- Чи є лише одна візуально головна CTA?
- Чи немає дубльованих даних про прогрес?
- Чи всі системні тексти однією мовою?
- Чи можна продовжити книжку за один тап із вкладки «Слухати»?
- Чи можна знайти книжку через пошук без переходу через кілька зайвих екранів?
- Чи можна керувати власними книжками, не плутаючи це з каталогом?
- Чи однаково поводяться Play, Download, Bookmark і меню на всіх екранах?

## Ключова формула

> **Слухати — відновити. Огляд — відкрити. Медіатека — керувати.**

Якщо кожен екран підтримує цю формулу, інтерфейс стане значно простішим, швидшим і візуально цілісним.
