## A. Підтверджені баги (є докази на пристрої/в коді)

### BUG-001 [HIGH] «Очистити» в Медіатеці стирає всі завантажені книги без підтвердження

- **Екран:** Медіатека (`03_library.png`)
- **Симптом:** кнопка «Очистити» поруч із рядком «Пам'ять пристрою: 0 MB · 0 аудіокниг
  offline» негайно видаляє ВСІ офлайн-книги — без жодного діалогу підтвердження.
- **Код:** `ui/screens/LibraryScreen.kt:336-340` → `ui/MainViewModel.kt:123-128`
  (`clearAllAudioCache`) → `data/downloads/OfflineDownloads.kt:221-233`:
  `audioDir.deleteRecursively()` усього `files/audiobooks/` + `markAllNotDownloaded()` +
  `clearAllTracksDownloadState()`.
- **Чому баг:** пряме порушення спеки 2026-08-13: «Physical file deletion without
  explicit confirmation (stays three-level)». Візуально кнопка виглядає як «очистити
  кеш», а стирає завантаження.
- **Відтворення:** 1) завантажити будь-яку книгу офлайн; 2) Медіатека → «Очистити»;
  3) книга втрачена, лічильник offline = 0, діалогу не було.
- **Очікувано:** діалог «Видалити всі завантажені файли (N книг, X MB)?» з
  Підтвердити/Скасувати; або кнопка прибрана (трирівневе видалення вже існує).
- **Фікс:** додати AlertDialog + юніт-тест на `clearAllAudioCache`.

### BUG-002 [HIGH] Дубль-картка книги з сирим SEO-заголовком («Трохи ненависті - АудіоКниги Українською»)

- **Екран:** Медіатека, Деталі книги (`03_library.png`, `04_bookdetail.png`)
- **Симптом:** одна й та сама книга 4read присутня в бібліотеці ДВІЧІ: чиста
  «Трохи ненависті» і «Трохи ненависті - АудіоКниги Українською» (сирий `<title>`
  сторінки 4read). Друга картка відкриває деталі з сирим заголовком, а її серія
  резолвиться в «1 книг у циклі» — тобто це окремий рядок БД.
- **Чому баг:** порушує спеки 2026-08-13/15 («deduplicated into single Work cards»,
  «one card per Work») і спеці 2026-08-16 (scrub SEO-суфіксів на сторінці).
- **Код/аналіз:** усі перевірені write-path нормалізують заголовок
  (`data/imports/LibraryImport.kt:106,388,458`, `upsertCatalogBook`,
  `writeWorkEdition`, `StoredTitleScrub` на старті додатка) — отже, рядок записано
  шляхом, що оминає `MetadataAssertions.normalizeTitle`, АБО UI читає таблицю
  (`editions`?), яку scrub не покриває. Кандидат-джерело: `SourceCatalog.kt:329`
  (`enrichFeedMatch` — копіює `detail.title` без нормалізації).
- **Відтворення (гіпотеза):** Деталі книги → «Джерела → 4read» (WebView) →
  повернутись → перевірити бібліотеку на новий рядок з сирим заголовком.
- **Фікс:** root-cause + регресійний тест («відкриття сторінки не створює другий
  рядок»); розширити `StoredTitleScrub` на всі таблиці, з яких читає UI; юніт-тест
  scrub на «Трохи ненависті - АудіоКниги Українською».

### BUG-003 [MED] Сирі заголовки фідів з емодзі та SEO-суфіксами на «Слухати»

- **Екран:** Слухати (`01_listen.png`)
- **Симптом:** рядки «Нове з джерел» показують сирий title джерела:
  «Аудіокнига Жертва з космосу - Роберт Шеклі 🎧слухати онлайн українською»,
  «Чужий серед своїх - АудіоКниги Українською».
- **Код:** `data/metadata/MetadataAssertions.kt` (`SEO_TITLE_PHRASES`, 5 фраз) —
  варіант «🎧слухати онлайн українською» не збігається жодною фразою (емодзі +
  комбінація не в списку), тому scrub не спрацьовує.
- **Фікс:** розширити `SEO_TITLE_PHRASES` (фрази «слухати онлайн українською» тощо)
  + обрізка емодзі з кінця заголовка; тести на реальні заголовки фідів.

### BUG-004 [MED] Лічильник «Книги (N)» в Медіатеці стрибнув 63 → 167 за одну сесію без дій користувача

- **Екран:** Медіатека (`03_library.png`)
- **Симптом:** о 08:43 — «Книги (63)»; ~о 09:05, після walkthrough без імпортів —
  «Книги (167)». Різниця +104 книги.
- **Гіпотеза:** фоновий `fetchCatalogSections` дописав каталог, а лічильник не
  оновлювався по ходу — лише при повторному відкритті.
- **Перевірити:** чи лічильник оновлюється по завершенню фонових sync (StateFlow
  `libraryBooks`/count), чи «замерзає» на першому значенні.
- **Фікс:** live-оновлення лічильника + тест.

### BUG-005 [MED] Серія «Епоха божевілля» резолвиться в «1 книг у циклі»

- **Екран:** Серія (`15_series.png`)
- **Симптом:** сторінка серії книги «Трохи ненависті» показує «1 книг у циклі» —
  лише сама книга. У RESULT round 2 для іншої серії було «7 книг у циклі» (механізм
  працює), отже тут або дані каталогу (серія з 1 книги на сторінці 4read), або збій
  резолюції серії/юніверсу (спека 2026-08-16, best-effort, тихий при невдачі).
- **Перевірити:** `series_members`/`series` у БД пристрою + сторінку серії на 4read.
- **Фікс:** за результатом перевірки — тикет з логом або фікс парсера/резолюції.

### BUG-006 [LOW] «1 книг у циклі» — українська плюральна форма

- **Екран:** Серія (`15_series.png`)
- **Код:** `ui/screens/SeriesScreen.kt:130` — `"${books.size} книг у циклі"`.
- **Симптом:** «1 книг» (має бути «1 книга»; для 2–4 — «книги»).
- **Фікс:** спільний helper множин («N книга/книги/книг», «N глава/глави/глав»,
  «N хвилин…») + юніт-тести; застосувати по всьому UI, де є такі рядки.

### BUG-007 [LOW] Дубль жанрових чіпів в Огляді

- **Екран:** Огляд (`02_explore.png`)
- **Симптом:** жанри є двічі: ряд «ЖАНРИ» (Казка, Вірші, Роман, Жахи, Драма) і
  фільтри «ВЕСЬ КАТАЛОГ» («Усі жанри» + ті самі Казка/Вірші/Роман…).
- **Фікс:** або прибрати з рядів, або об'єднати з фільтрами; звірити зі спекею
  2026-08-15 («search + genre/mood chips on top»).

### BUG-008 [LOW] Listen рендерить 8 блоків замість 5 зі спеки

- **Екран:** Слухати (`01_listen.png`)
- **Код:** `ui/library/ListenComposer.kt:36-43` — HERO, ALMOST_DONE, RETURN,
  NEXT_IN_SERIES, TRAVEL, SHORT, FAVORITE_AUTHORS, RECENTLY_ADDED.
- **Симптом:** спека 2026-08-07 фіксує 5 блоків; «Щось коротке» (SHORT) описано
  лише в `docs/wayfinder/prototype/personalized-listen.md` (прототип, не спека).
- **Рішення:** або спека під поточний набір блоків, або зрізати до 5.

### BUG-009 [LOW] Чіпи фільтрів Медіатеки відхиляються від спеки

- **Екран:** Медіатека (`03_library.png`)
- **Симптом:** фактичні чіпи: Усі / Слухаю / Завершені / Завантажені / Нещодавно
  слухані. Спека 2026-08-13: All / Listening / Finished / Downloaded / **Local** /
  **Online** / **Favorites** (немає Local/Online/Favorites, є зайвий «Нещодавно
  слухані»).
- **Рішення:** звірити набір зі спекею (або оновити спеку, якщо набір усвідомлено
  змінений).

## B. Підозри, що потребують перевірки (INFO)

### BUG-010 [INFO] Hero «Продовжити слухати»: «0% · Залишилося 16 год 32 хв» при позиції 2:35:44/16:41:11

- Спека 2026-08-16 вимагає **кумулятивну** позицію книги (глави до поточної +
  offset всередині глави), а не in-chapter ÷ сума. 0% може бути чесним округленням
  (≈0.9%), але формулу перевірити юніт-тестом.

### BUG-011 [INFO] «Narrated by Pik CAH4E3» на деталях книги

- Спека 2026-08-16: «Читає …» рендериться лише для реальних імен. Перевірити, що
  «Pik CAH4E3» — це справжній атрибут сторінки 4read (не транскод), інакше він має
  пройти brand-scrub (`normalizeClaimedText`).

### BUG-012 [INFO] Кнопки транспорту плеєра «15» без підпису

- `05_player.png`: кнопка «15» (перемотка назад) без іконки/підпису поруч із «30».
  Перевірити `contentDescription` (доступність/TalkBack) і візуальну консистентність.

### BUG-013 [INFO] «Книги (63)» → можливий недолік чесних даних: `03_library.png` «Пам'ять пристрою: 0 MB · 0 аудіокниг offline»

- Лічильник пам'яті відповідає даним на момент знімка. Перевірити, що він
  оновлюється після завантаження книги (без рестарту екрана).
