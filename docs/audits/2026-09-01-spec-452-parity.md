# Паритет дій картки «Огляду» (#461)

Це фінальна таблиця для #452. Вона фіксує одну поведінку Android і Web, а не
два схожі набори повідомлень. Автоматичний тест є обов’язковим для кожного
детермінованого правила. Живі джерела лишаються окремим ручним smoke: CI не
має падати через чужий сайт.

## Android device smoke

- [ ] Direct Source: відкрити картку, окремо натиснути Play, дочекатися звуку.
- [ ] Browser Source: пройти challenge один раз і відкрити дві різні книги того самого Source.
- [ ] Перезапустити застосунок: друга книга використовує ту саму чинну сесію.
- [ ] Дочекатися/імітувати expiry: картка показує «Потрібна перевірка на сайті» і не відкриває WebView сама.
- [ ] Натиснути «Відкрити сайт», відновити сесію й повернутися до тієї самої картки.
- [ ] Очистити одну Source-сесію в налаштуваннях і перевірити, що інша лишилася.

## Web smoke

- [ ] Keyboard: Tab фокусує тіло картки, потім окремий Play; Enter виконує саме вибрану дію.
- [ ] Direct audio: Player відкривається лише після звуку/події `playing`.
- [ ] Заблокувати direct URL: relay підхоплює ту саму Edition.
- [ ] Вимкнути Worker після warm load: видно timestamp останнього каталогу; відкриті картки не зникають.
- [ ] Append без Worker показує retry й не стирає попередні сторінки.
- [ ] 4read пояснює потребу сесії та відкриває сайт лише після натискання; cookies не передаються Worker.
