# Компактний фільтр мови — #548

База змін: `bb6fb5a7`, гілка `codex/release-1.3.9-preparation`.

## Результат

Панель показує 🌐 для всіх мов, 🇺🇦 для української та 🇬🇧 для англійської. Кнопка має розмір 56×48 dp, вибраний стан і повну локалізовану назву для TalkBack. Символ поводиться як іконка й не розтягує панель при збільшенні шрифту.

На вузькому екрані сортування й фільтри показують компактні іконки з доступними назвами. На ширшому залишаються підписи. Усі три контролі мають висоту 48 dp. Вибір мови передається як набір кодів, тому символ не залежить від перекладу назви або мови інтерфейсу.

Запит Edition і сховище мовних налаштувань не змінювалися. Натискання використовує наявний цикл мов; інші фільтри зберігаються.

## Перевірено

- `WorkFeedFilterAccessibilityTest`: цільовий тест спочатку впав на старому текстовому контролі; після зміни група пройшла.
- `WorkFeedFilterWiringTest`: 4 тести пройшли. Реальні Room/Pager-результати змінюються після натискання мовного фільтра. Очікування назви адаптовано до ресурсів мови інтерфейсу.
- `LanguageFilterTest` на телефоні: реальний цикл усі → українська → англійська → усі з активними жанром, тривалістю й сортуванням; вони не змінилися. Початкові налаштування відновлено в `finally`.
- Компонування на телефоні: 18 варіантів — три мовні стани, uk/en інтерфейс, 320 dp / 100%, 400 dp / 130%, 320 dp / 200%. Контролі не накладаються, мають однакову висоту та повні доступні назви.
- `EditionLanguageFilterDeviceTest`: реальний Android SQLite в окремій базі в пам’яті. Перевірено відбір українських та англійських Edition, видимість невідомої мови, змішані Edition одного Work та поєднання з жанром. База користувача не відкривається.

Разом останній телефонний прогін: 3 тести, 18,178 с, успішно. APK debug 1.3.9 установлено зі збереженням даних; SHA-256: `da734edfc05672c95419edef72c6df0f63fcdb16084d66887ec1165b76e5286e`.
