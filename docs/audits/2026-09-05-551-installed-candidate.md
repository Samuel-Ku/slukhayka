## Локальні тести

Групи повного набору доперевірено частинами. Початковий `scripts/test-all.sh`
не завершився; після усунення проблем середовища запускалися тільки перервані
та ще не виконані класи. Наприкінці звірено не лише назви класів, а й кожний
оголошений тестовий метод перерваних груп.

| Група | Результат |
| --- | --- |
| Pure JVM, Room native SDK 35 | Пройшли в початковому прогоні. |
| Room default | Пройшла; три opt-in тести Firestore Emulator пропущені. |
| Room native SDK 36 | Є успішний результат усіх 479 оголошених тестових методів у 56 класах. |
| Robolectric-only | Доперевірено всі методи 49 класів; останній залишок — 182 перевірки за 4 хв 41 с. |
| Compose/Roborazzi | Є успішний результат усіх 128 оголошених тестових методів у 28 класах. |

Звичайні спільні JVM-процеси на цьому Mac зависали. Для продовження
використано тимчасові init-файли з `-XX:TieredStopAtLevel=1`, а для останніх
Room-сценаріїв — `-Xint`. Два класи Compose додатково запускалися з
`forkEvery=1`. Код продукту та очікування тестів даних для цього не змінювалися.
Це перевірка всього набору по частинах, а не успішний безперервний запуск
зі стандартною конфігурацією JVM.

Початково на Mac закінчувалося місце. Прибрано лише невикористовувані тимчасові
native-кеші Robolectric, перевіривши відсутність відкритих файлів. Вільне місце
зросло до 7,4 GiB. Пошкоджені бінарні результати Gradle збережено в
`/tmp/slukhayka-551-corrupt-test-results`. Завислі процеси власних завершених
прогонів прибрано; інші тестові процеси не зупинялися.

Ізоляція виявила п’ять застарілих перевірок видимого тексту компактних кнопок
у `WorkFeedToolbarSnapshotTest` та `HomeFeedPhoneFoldSnapshotTest`. Після #548
ці кнопки можуть бути іконками. Селектори тепер перевіряють сам контрол і повну
доступну назву. Перевірки вибору, скидання, прокручування та закріплення панелі
збережено. Фінальні прогони: чотири тести панелі та три тести огляду пройшли.
Standards і Spec review не мають блокерів. Продуктовий APK не змінено.

## Що залишається

Актуальне підтвердження чутного звуку та залишкові межі UI-аудиту зі звітів
#549–550. Реальне відновлення з несправного джерела,
Tor/проксі цим фінальним прогоном не перевірялися. Частина підписів медіатеки,
книги та діалогів залишається українською в EN-контексті.
Контрольовані error-fixtures підтверджують повідомлення та доступність дій,
але не замінюють мережевий сценарій. Готовність усього релізу цим звітом не заявляється.
