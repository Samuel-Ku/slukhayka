# Прототип-вердикт: аудіо з публічного превʼю t.me/s — грає без логіну?

> Статус: **ЧЕРВОНИЙ** — превʼю не містить аудіо взагалі; грати без логіну
> нічому. TG-надходження публікуються як **метадані** з чесним «Джерело
> недоступне» для плейбека інших (ADR-0035 п. 13, спека #601 AC3).
> Перевірка на пристрої залишається рунбуком нижче (патерн `docs/phone-test/PLAN.md`).

## Що перевірялося (веб-рівень, 2026-09-08)

Канал **@stivenkingua** (єдиний із перших десяти з публічним превʼю —
решта каналів віддають «Preview unavailable»). Завантажено:

- `https://t.me/s/stivenkingua/260` — 85 КБ HTML, 10 постів-віджетів;
- `https://t.me/stivenkingua/166?embed=1` — 18 КБ HTML, рівно один пост (ембед).

## Докази

1. **Кнопка «Слухати» — не аудіоплеєр.** У кожному пості це
   `tgme_widget_message_inline_button url_button`, чий `href` веде на
   **приватні інвайт-посилання**: `https://t.me/+v_6X9daxx2U5Y2Iy`,
   `https://t.me/+khrCMdYLrqNmM2I6`, `https://t.me/+o7i1Nwshp2k5MmU6`…
   Аудіо живе за інвайтом/логіном, не в превʼю.
2. **У HTML превʼю немає жодного аудіо-носія**: жодного `<audio>`, `<video>`,
   класів `tgme_widget_message_voice` / `message_audio`, файлів
   `.mp3`/`.m4a`/`.opus`, CDN-стрім-адрес (`cdn*.telegram-cdn.org` — лише
   фото-обкладинки на `cdn4.telesco.pe`).
3. Превʼю несе рівно три речі: **текст посту** (Channel Post Pattern —
   заголовок, `🔊Читає:`, серія, опис), **обкладинку** (фото посту як
   «твердження джерела», ADR-0020 останній рівень) і **реакції/метадані**.
4. Сторінка `t.me/s/<канал>/<id>` рендерить **останні 10 постів**, а не
   вказаний; точний пост дає лише ембед `?embed=1` — це канонічний шлях
   завантаження для надсилання.

## Висновок

Публічне превʼю **не відкриває аудіо без логіну** — воно не містить аудіо
взагалі. Звідси:

- `TgPreviewSourceAdapter.parseCapturedPage` завжди віддає **порожні
  розділи** (чесний недоступний стан, ADR-0019) — ідентичність Твору
  (TitleNormalizer, T1) + опис + обкладинка як метадані;
- надсилання публікується як **metadata-only** документ (`accessMode =
  tg_preview`, без розділів, `verifiedAt = 0` — вердикт програвання
  неможливий за червоного прототипу); інші інсталяції бачать Твір і
  чесний недоступний стан (проєкція #605);
- **зелений** прототип (майбутній): адаптер починає віддавати розділи з
  аудіо-URL посту, надсилання йде повним ланцюгом T3 (копія →
  верифікація → публікація).

## Рунбук на пристрій (залишкова перевірка AC1)

1. `adb devices` — телефон/емулятор підключено.
2. Вставити в поле надсилання `https://t.me/stivenkingua/166` (або будь-який
   пост каналу), надіслати.
3. Очікувано (червоний вердикт): у медіатеці/каталозі з'являється Твір
   «Темна вежа» (Стівен Кінг) без джерел; спроба відтворити показує чесний
   «Джерело недоступне» / «Немає розділів» — жодного звуку, жодної вигаданої
   адреси.
4. Якщо аудіо раптом заграло без логіну — вердикт перевертається на ЗЕЛЕНИЙ
   (див. вище) і оновлюється цей документ.
