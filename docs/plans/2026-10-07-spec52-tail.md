## Збірки

Gradle у цій машині працює лише з `GRADLE_USER_HOME` усередині робочої копії
(`~/.gradle` для пісочниці read-only). Важка збірка має **один слот**:
запуск лише через `.worktrees/gt` (flock на `.worktrees/.build-slot`).
Паралельні прогнали Gradle заборонені. Цільові тести замість повного набору.
Перед кожним PR — перечитати актуальний `main`.
