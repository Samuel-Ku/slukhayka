# План: #1532 — «Новинки» на головній не показують сирий маркер «unknown»

Follow-up до #1528 (display-шар). Після #1487 зріз 2 у медіатеці є картки,
імпортовані зі сторінки **невідомого** хоста під внутрішнім маркером
`UNKNOWN_SOURCE_ID` (`"unknown"`). Медіатека і сторінка книги маркер уже
ховають (#1528), але «Новинки» на головній — ні:

- `LibraryNewArrivals.project` будує `sourceName = sourceDisplayName(sourceIdForUrl(url))`;
  для probed-картки це `"unknown"`;
- `HomeScreen.NewArrivalsRail` рендерить `MetadataChip` для будь-якого
  непорожнього `sourceName`.

## Рішення

1. **`sourceDisplayName(UNKNOWN_SOURCE_ID)` повертає порожній рядок.** Маркер
   за власним KDoc — «internal marker, never a name to show» (`GlobalSearch.kt`),
   тож центральне місце, де id перетворюється на людську назву, і є правильна
   точка виправлення: порожнє ім'я означає «немає чого показувати», а не
   вигадану назву.
2. **Жодних нових псевдонімів** («Веб-сторінка»): це виглядало б як
   зареєстроване джерело й вимагало б локалізації; фактичне джерело — URL
   сторінки, він лишається в даних.
3. **UI не змінюється:** `NewArrivalsRail` уже ховає чіп при порожньому
   `sourceName` (`if (arrival.sourceName.isNotBlank())`), тож картка
   лишається, зникає лише хибний чіп. Той самий ефект — для будь-якого іншого
   споживача `sourceDisplayName`, якому маркер міг протекти (стрічки джерел,
   кандидати доступності).

## Межі (названі)

- фільтр — точна рівність `UNKNOWN_SOURCE_ID`, не евристика; зареєстровані
  джерела (soundbooks, lihtar, local…) повертають ті самі назви;
- display-шар: імпорт, плейбек, дедуп, бюджет не змінюються;
- сторінка книги продовжує фільтрувати рядок джерела (#1528) — там порожній
  рядок у секції не потрібен, маркер просто не є джерелом.

## Перевірка

- `LibraryNewArrivalsTest`: probed-картка дає `sourceName == ""` (і чіп не
  рендериться — наявна умова UI), відомі джерела лишаються з назвами.
- `GlobalSearchRepositoryTest`: `sourceDisplayName("unknown") == ""`, а
  зареєстровані id — без змін.
- Мутація: прибрати special-case → нові тести червоніють.
- Цільові: `:app:testPureJvm` для двох класів; повний матрикс — CI.
