# План: #1560 — рядок «Додати до добірки» стає одним контролом

В аркуші `AddToCollectionSheet` інтерактивним був лише `Checkbox`; `Row`
навколо мав `heightIn(min = 48.dp)`, але без `clickable`/`toggleable`, тож
тап по назві добірки (≈80 % рядка) не робив нічого. Для TalkBack чекбокс був
окремим вузлом **без назви** (назва — сусідній `Text`), тому озвучувався як
безіменне «поле перемикання». ADR-0044/0033 і talkback-чеклист вимагають
одного вузла з назвою й станом.

## Рішення

1. `Row` отримує `Modifier.toggleable(value = alreadyThere,
   role = Role.Checkbox, onValueChange = { onToggle(...) })` — увесь рядок
   стає ціллю 48 dp; логіка `onToggle` та стан не змінені.
2. `Modifier.semantics(mergeDescendants = true)` зливає рядок в один
   семантичний вузол: назва добірки + роль перемикача + стан.
3. `Checkbox(onCheckedChange = null)` лишається ЛИШЕ візуальним: він не є
   окремою ціллю й не дублює жест.
4. Два тести: тап по назві перемикає (той самий `onToggle`); семантичний
   вузол має `ToggleableState`, `Role.Checkbox` і текст назви.

## Межі (названі)

- змінюється лише рядок наявної добірки; створення нової добірки, порожній
  список і збереження не чіпаються;
- справжній голос TalkBack і вигляд на пристрої лишаються за власником:
  JVM-тест пінить семантику (роль/стан/назва) і жест, не синтез мовлення.

## Перевірка

- `:app:testRoomRobolectric -Ptest.selectedClasses=…AddToCollectionSheetTest`
  — наявні + 2 нові зелені.
- Мутація «`onValueChange` нічого не робить» → новий тест тапу червоніє;
  мутація «прибрати `toggleable`» → семантичний тест червоніє.
