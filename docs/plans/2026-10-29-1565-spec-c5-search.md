# План: #1565 — C5 спеки v1.4 наздоганяє ADR-0033 (постійно видимий пошук)

`docs/specs/2026-09-06-ui-consistency-v14.md` (C5) описував Android-пошук
як «колапсуючий патерн Огляду (🔍 у шапці, ✕/Back очищає)». ADR-0033
(«Зміна рішення 2026-09-18») відкинув це: єдиний патерн — постійно видиме
поле на коренях; 🔍 не існує, ✕ лише очищає, Back спершу очищає запит. Код і
`CONTEXT.md` уже синхронізовані (останнє — #1559); спека лишалася єдиним
місцем із протилежним твердженням.

## Рішення

1. C5 переписується під Android-реальність з посиланням на ADR-0033
   «Зміна рішення 2026-09-18».
2. Історична вимога не переписується заднім числом: явно сказано, що
   початковий текст C5 **замінено** рішенням 2026-09-18.
3. Web-дельта названа: згортуваний жест лишається свідомою дельтою
   (ADR-0034, W3.4); US-2-тести обов'язкові для обох платформ.
4. Решта C5 (шапка таба, бренд, `SpaceAboveMiniPlayer`, snapshot шапок) не
   змінюється; коду PR не торкається.

## Перевірка

- `python3 scripts/doc_numbers.py` — exit 0;
- докові гейти CI (docs-класифікація) — зелені;
- оглядач звіряє текст із ADR-0033 §«Зміна рішення 2026-09-18» і кодом
  (`HomeScreen.kt`/`LibraryScreen.kt`).
