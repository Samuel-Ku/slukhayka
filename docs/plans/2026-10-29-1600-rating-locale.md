# План: #1600 — рейтинг у «Медіатеці» без коми

`LibraryRatingScreen.kt:202` форматував середню оцінку через
`Locale.getDefault()`, тож на uk/pl екран показував «4,5», тоді як усі інші
рейтингові поверхні (картки добірок, сторінка книги, відгуки) — «4.5»
(`Locale.US`). Це не локалізаційне правило: десяткові оцінки в застосунку
послідовно з крапкою; `Format.kt` окремо локалізує лише одиниці розміру.

## Рішення

1. `formatRatingAverage()` → `String.format(java.util.Locale.US, "%.1f", …)`.
2. Тест `LibraryRatingFormatTest`: під `Locale.setDefault(uk)` і `pl`
   (з відновленням у `@After`) — «4.5»/«4.0»/«0.0», без коми.
3. Решта кодових місць не чіпається.

## Межі

- один рядок форматування + один юніт-тест; UI/геометрія/голдени не змінені.

## Перевірка

- `:app:testPureJvm -Ptest.selectedClasses=…LibraryRatingFormatTest` — зелені.
- Мутація: `Locale.US` → `Locale.getDefault()` → новий тест червоніє на uk.
