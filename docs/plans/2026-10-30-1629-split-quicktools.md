# План: #1629 — quick tools у панелі плеєра в landscape-split

QA на OnePlus 8 Pro у landscape split: ліворуч бібліотека, праворуч ink-плеєр.
Рядок швидких інструментів не вміщався — «Таймер», «Закладка», «Розділи»
рендерились як «Тай…», «Зак…», «Роз…», а hero лівої панелі обрізався правим
краєм.

## Причина

З #1205 плеєр стає **правою панеллю** вікна ≥840 dp: панель = 0.6 ширини
(905 dp → 543 dp), але висота лишається 411 dp. `PlayerScreenContent` вибирає
двоколонковий landscape-layout за **вікном** (905×411), тож усередині панелі
права контрольна колонка отримує `(543−32)×1.15/2 ≈ 294 dp`. Після F7/F32
кожен quick tool — ОДИН рядок (іконка+підпис), тож чотири рівні чипи ділять
294 dp → ≈73 dp на чип, а «Закладка»/«Розділи» з іконкою потребують ~80 dp →
`TextOverflow.Ellipsis` («Зак…», «Роз…»). У повноекранному landscape
(905 dp) колонка вдвічі ширша — там усе вміщалося, тому дефект видно лише в
панелі.

## Рішення

1. **QuickTools міряє, а не вгадує:** `TextMeasurer` бере найширший видимий
   підпис (`labelMedium`, той самий стиль, що рендериться) і порівнює
   `maxWidth / 4` з `icon + 4 dp + widest + 8 dp`.
2. **Не вміщається → 2×2:** ті самі чотири `QuickTool` розкладаються двома
   рядами по два; кожен слот отримує удвічі більше ширини, підпис цілий.
3. **Compact-чип лишає 48 dp touch target**, але без зайвого vertical padding —
   другий рядок уміщається у 411 dp панелі, не зсуваючи транспорт за край
   (перевірено межами чипів у тесті).
4. **Повноширинний landscape не змінюється:** 4 чипи в один ряд, як у F7/F32.

## Межі

- змінюється лише розкладка рядка quick tools (і padding compact-чипа);
  іконки/підписи/a11y-описи/labels — ті самі;
- hero (обкладинка+ідентичність) у панелі піниться межами, без зміни коду;
- жодних нових рядків ресурсів.

## Перевірка

- `PlayerPaneQuickToolsFitTest` (905×411, панель 543/460 dp, fontScale
  1.0/1.15): жоден `TextLayoutResult` quick tool не еліпситься (всі рядки),
  чипи в межах панелі, hero-обкладинка в межах; повноширинний 905 dp —
  один ряд (top спільний).
- `LandscapePhoneLayoutTest`, `WidePlayerPaneTest`, `PlayerAccessibilityTest` —
  регресійні; Compose+Roborazzi еталони — CI-гейт.
- Мутація `compact = false` (ніколи не переносити) → тест падає.
