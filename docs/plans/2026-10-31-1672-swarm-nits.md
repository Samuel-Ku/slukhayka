Три не-блокуючі ніти незалежного огляду PR #1671 (#1670), тест-only.

## 1. Застарілий docstring модуля

Шапка `scripts/tests/test_swarm_bootstrap_check.py` казала «неіснуючий
`$REPO_DIR`», хоч після #1670 це робить лише один із двох тестів (нормальний
шлях створює `repo/.git`), і перелічувала `#1666/#1668` без #1670.

Оновлено: три дефекти (#1666 pgrep, #1668 df/pipefail, #1670 normal-path), і
описано ОБИДВА стани фікстури (`create_repo: True|False`), включно з
`assertIn("[check] FAIL диск (")`.

## 2. Друкарська помилка

`# - -check` у коментарі фікстури → `--check`.

## 3. `assertIn("клон репозиторію")` приймав і `ok`, і `FAIL`

У тесті відсутнього клона assert не розрізняв стани, тож мутація «клон завжди
ok» (`[ -e / ]` замість `[ -e "$REPO_DIR/.git" ]`) виживала обидва тести
(2 OK) — той самий клас, що #1670 лікував для диска.

Тепер `assertIn("[check] FAIL клон репозиторію", proc.stdout)`.

## Перевірка

- `python3 -m unittest discover -s scripts/tests -p "test_swarm_bootstrap_check.py"` → 2 OK.
- Red/green: мутація `[ -e / ] && ok "клон репозиторію"` → тест відсутнього
  клона падає на `FAIL клон репозиторію`; на вихідному — 2 OK.
