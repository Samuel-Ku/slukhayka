# План: #1693 — підпис слухача: локаль-залежна презентація, без дублю фрази

Follow-up огляду PR #1692 (#1687), WARN 1–5.

## Причина

- дефолтний псевдонім «Слухач»/«Listener» народжувався в `listenerIdentity`
  **другим хардкодом** тієї самої видимої фрази, що й ключ `listenerFallback`
  — могли розійтися тихо;
- `nicknameFor(uid)` викликав поточний `getUiLocale()` при КОЖНОМУ читанні, але
  `App` тримав `profile.nickname` у стані, тож після перемикання мови в шапці
  старий підпис («Слухач-NNNN») лишався до перезавантаження (залишковий AC4);
- у `saveReview` гілка `profile?.nickname ?? t("listenerFallback")` була мертва:
  `uid === null` уже відсікався, а `profile` непорожній ⇒ nickname рядок.

## Рішення

1. **Одне джерело фрази:** `defaultListenerName(locale)` =
   `translate(locale, "listenerFallback")`; окремого хардкоду немає.
2. **Чесна семантика:** `nicknameForUid(uid, locale)` — псевдонім є
   ПРЕЗЕНТАЦІЄЮ uid (base за локаллю + той самий хеш-суфікс; `local-…` uid без
   суфікса, як і раніше). `localizedProfile(profile, locale)` локалізує ЛИШЕ
   згенерований дефолт (`isGeneratedNickname` — точний збіг із
   `nicknameForUid(uid, uk|en)`); власний нік повертається байт-ідентичним,
   uid не змінюється.
3. **Реактивність:** `App` тримає `baseProfile` і обчислює `profile` через
   `useMemo(localizedProfile(baseProfile, locale))`; перемикання мови в шапці
   перерендерює підпис одразу, без reload. `setProfile` лишається сумісним.
4. **Мертву гілку прибрано:** `saveReview` робить `if (profile === null) return`
   і пише `authorName: profile.nickname` (вже локалізований App-ом).
5. Персонально вибраний нік не чіпається: `isGeneratedNickname` порівнює
   збережений `nickname` з двома згенерованими формами; усе інше — дані
   слухача, повертаються без змін (є свідок на App-рівні).

## Тести (+3)

- `listenerIdentity.test.ts`: `nicknameForUid` — uk/en базові назви, той самий
  хеш-суфікс для того самого uid, `local-…` без суфікса; `localizedProfile`
  зберігає uid і перекладає підпис в обидва боки.
- `nicknameLocale.test.tsx` (реальний `<App/>`): Налаштування → Профіль,
  **літерал** `Слухач-4379`; `act(() => setUiLocale("en"))` → літерал
  `Listener-4379` (те саме число), без reload; власний нік «Книголюб»
  лишається байт-ідентичним після перемикання.

## Мутації (свідки)

- `App` ігнорує локаль (`profile = baseProfile`) → App-тест червоний;
- `defaultListenerName` повертає жорстко «Слухач» → 4 identity-тести червоні;
- прибрати `isGeneratedNickname`-перевірку → 2 тести власного ніка червоні;
- змінити hash (`* 31` → `* 33`) → літеральний тест хешу червоний.
