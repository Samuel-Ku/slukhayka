# «Папір і голос» — інтерактивний прототип

Прототип візуального напряму 2026–2027 для Android-застосунку «Слухайка» (Compose)
і веб-плеєра. Специфікація: [`../../specs/2026-10-26-ui-refresh-2027.md`](../../specs/2026-10-26-ui-refresh-2027.md).

## Як відкрити

- Просто відкрити `index.html` у браузері — усе локальне, без мережі й CDN.
- Один екран на весь вікно: `index.html?only=listen|overview|library|player|book|achievements`.
- Скріншоти восьми екранів (2×): [`screens/`](screens); контактний аркуш — `screens/contact-sheet.jpg`.

## Що всередині

| Файл | Призначення |
|---|---|
| `index.html` | дошка: діагноз, напрям, палітри, типографіка, 8 екранів, «було → стало», компоненти, таблиця розмірів, план, ревізія |
| `assets/app.css` | токени й компоненти застосунку (обидві теми, 412×915 dp) |
| `assets/board.css` | оформлення самої дошки (не частина застосунку) |
| `assets/fonts/` | Onest + Literata, woff2, сабсети кирилиця/латиниця; повні тексти OFL — `app/src/main/assets/licenses/ofl-onest.txt` і `ofl-literata.txt`, а не в `fonts.css` |
| `assets/covers/` | демонстраційні обкладинки з тестових наборів репозиторію |
| `assets/0*.webp` | поточний стан застосунку (старі знімки) |
| `assets/after-*.png` | зменшені рендери нових екранів для пари «було → стало» |
| `screens/*.jpg` | репрезентативні фінальні рендери (стиснуті), плюс `contact-sheet.jpg` |
| `compare-player.html` | приклад до рішення про плеєр: A — завжди «Чорнило», B — плеєр у темі застосунку |

Дані на екранах демонстраційні (книги, автори, обкладинки з наявних тестових наборів),
щоб оцінювати форму, а не контент.

## Як перерендерити

```bash
chromium --headless --disable-gpu --hide-scrollbars \
  --force-device-scale-factor=2 --window-size=412,915 \
  --screenshot=screens/player.png \
  "file://$PWD/index.html?only=player"
```

Усі розміри на макетах — у dp. При `--force-device-scale-factor=2` зображення 2×: 2 px = 1 dp.

## Обмеження

- Це браузерний макет, а не Compose-рендер: тіні, blur, кольори й шрифти імітують,
  але не доводять поведінку на Android. План переносу — §8–9 специфікації.
- Ефект скла в міні-плеєрі на Android отримує opaque-fallback для API < 31.
- Демонстраційні обкладинки належать їхнім джерелам; у застосунку використовуються
  лише як тестові дані.
