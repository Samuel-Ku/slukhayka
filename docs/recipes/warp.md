# Рецепт: Cloudflare WARP як маршрут

spec-38 T6. WARP — це VPN до мережі Cloudflare, а не анонімізація: джерело
бачить адресу виходу Cloudflare, але **Cloudflare бачить весь ваш трафік**,
а акаунт прив'язаний до вашої особи/пристрою.

## Крок 1. Встановіть 1.1.1.1 (WARP)

Google Play / App Store: застосунок «1.1.1.1: Faster Internet» від Cloudflare.
Увімкніть режим WARP (не лише DNS) — іконка має показувати активний тунель.

## Крок 2. Маршрут у застосунку

WARP — системний VPN: окремий маршрут у застосунку не потрібен. Поставте
«Пряме з'єднання», щоб трафік пішов у тунель як є. Якщо хочете приховати домени
від локальної мережі — увімкніть DoH (увімкнений за замовчуванням).

## Що знати (чесні обмеження)

- **Не Tor**: WARP шифрує трафік до Cloudflare, але не робить вас анонімним
  для джерел (спільний вихідний діапазон Cloudflare) ні для Cloudflare.
- **Конфлікт із проксі**: активний VPN перехоплює весь трафік; маршрути
  HTTP/SOCKS5/Tor застосунку йдуть усередину тунелю — це працює, але подвійне
  загортання сповільнює з'єднання.
- **ToS**: використання WARP для обходу регіональних обмежень може порушувати
  умови Cloudflare; для читання аудіокнижок це нецільове, але можливе побічне
  явище — майте це на увазі.
