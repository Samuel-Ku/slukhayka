тунелів і даних доступу. Приватні деталі робочого середовища лишаються поза

## Що зроблено

### Каталог

- `scripts/recommend/catalog_from_ukrainian.py` — sitemap/JSON підтримуваних
  українських джерел: soundbooks, audiobook.co.ua, chytaylo, knigi-online,
  sluhay, chitaka; решту до `--limit` добирає LibriVox.
- `scripts/recommend/catalog_from_librivox.py` — публічний API LibriVox.
- `scripts/recommend/catalog_from_seed.py` + `seed-catalog.json` — 23 реальні
  seed-книжки застосунку для малого фікстура.
- `scripts/recommend/merge_key.py` — один Python-порт `MergeKey.keyFor`;
  Kotlin-тести звіряють його з Android.
- Українські джерела: soundbooks 2 154; audiobook.co.ua 1 709; chitaka 8 150;
  chytaylo 915; knigi-online 390; sluhay 507 (мінус дублікати за ключем).
- Chitaka: 8 244 сторінки, 4 воркери — без блокувань; 12 воркерів викликали
  403. Дефолти: `--workers 4 --chitaka-limit 9000`.

### Воркер

- `scripts/recommend/build_graph.py` — офлайн, `--model-dir`, без мережі;
  `MAX_WORKS=20_000`, `MAX_BYTES=8 MiB`; `fit_artifact()` сам зменшує top-k,
  якщо артефакт не влазить (для 20k вийшло 21).
- systemd-юніт з `DynamicUser`, `PrivateNetwork`, `IPAddressDeny=any`,
  `RestrictAddressFamilies=AF_UNIX`, `ProtectHome`, `ProtectSystem=strict`,
  порожніми capabilities. `MemoryDenyWriteExecute=no` — обов'язково для
  numpy/OpenBLAS; `yes` ламає `pthread_create`.
- `RuntimeMaxSec` для `Type=oneshot` ігнорується; обмеження — `TimeoutStartSec`.

### Підпис і доставка

- `scripts/recommend/deliver_graph.py` — окремий операторський процес:
  ECDSA P-256/SHA-256 через `openssl`, перевірка підпису перед записом;
  результат — точні `graph.json` + `graph.json.sig` (base64 DER).
- Модельний процес ключа не має; ключ і store — поза репозиторієм і поза
  робочим каталогом моделі.
- `scripts/recommend/serve_graph.py` — локальна віддача лише двох файлів;
  лістингу й traversal немає.

### Android

- `GraphSignatureVerifier.kt` — pinned ECDSA P-256 (Base64 DER SPKI).
- `RecommendationGraphStore.kt` — перевіряє підпис і завантаженого, і
  кешованого графа; без валідного підпису кеш не замінюється; `.sig` береться
  як `<url>.sig`; одна спроба на добу; атомарна заміна.
- `MainViewModel.kt` передає `BuildConfig.RECOMMENDATION_GRAPH_URL` і
  `RECOMMENDATION_GRAPH_PUBLIC_KEY`.
- `app/build.gradle.kts`: `-Precommendation.graphUrl` (лише https) і
  `-Precommendation.graphPublicKey` (Base64). URL без ключа валить збірку;
  без URL мережевий шлях вимкнений.
- Тести: `SeedCatalogKeyTest`, `LibriVoxKeySampleTest`,
  `SeedGraphSignatureTest`, `GraphSignatureVerifierTest`,
  `RecommendationGraphTest`, `GraphScaleTest` (20 000 × 22).

### Активація

- Debug APK зібраний локально з pinned URL і ключем; у BuildConfig вони

## Пастки

- `MemoryDenyWriteExecute=yes` ламає numpy/OpenBLAS (`can't start new thread`).
  На хості — `no`.
- `RuntimeMaxSec` не працює для `oneshot`; використовувати `TimeoutStartSec`.
- Chitaka: 4 воркери; 12 викликали 403. Не збільшувати конкурентність.
- Фінальний 20k-каталог збирався двома проходами (основний скрипт без
  chitaka + окремий merge для chitaka). Комітнутий
  `catalog_from_ukrainian.py` з `--workers 4 --chitaka-limit 9000` має
  відтворити набір, але одним проходом це не перевірялося.
- APK підписаний debug-ключем; release-версію з іншим підписом спершу
  видалити.
- URL підпису — `<graph-url>.sig`; URL має бути статичним шляхом без query.
- `review:pass` не «полагодити» повторним додаванням label: потрібен
  `scripts/review-pass.sh` і свіжий незалежний review.

## Безпека

- Воркер офлайн: без мережі, без ключа, без історії слухача; лише публічні
  метадані. Каталог і граф не містять listener-полів.
- Модельний процес не має signing key; ключ — лише в оператора доставки.
- Жодних нових вхідних портів для рекомендацій. HTTPS-хост віддає лише
  публічний артефакт; тимчасовий тунель після приймання зупиняється.
- Приватні адреси, SSH-доступи, ключі й дані середовища не комітяться.
  Віддалена робота налаштована окремо; деталі — у власника.
- Не мерджити без свіжого review; не публікувати реліз без домену,
  сертифіката й keystore.
