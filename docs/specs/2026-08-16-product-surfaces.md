# Product surfaces without an owning spec — 2026-08-16

> Походження: технічна ревізія екранів `2026-08-16-screens-revision.md`
> (розділ 3.2 «Екрани без док-джерела»). Цей файл дає кожній сутності
> призначення, походження і критерій «працює», щоб фіча не висіла «unowned».
> Рішення структури узгоджені в spec-27 (#184).

## Рішення по сутностях (keep | document | remove)

| Сутність | Рішення | Куди в продукті |
|---|---|---|
| Top100Screen | keep | екран; вхід — картка «ТОП 100» в Огляді |
| PeopleScreen / PersonBooksScreen | keep | екрани; вхід — картки «Виконавці» / «Автори» |
| GenreScreen (повна сторінка) | keep | browse-сторінка каталогу через спільний BookListScreen; вхід — тап по жанру в картці книги |
| ChaptersSheet | **fold** | згортається в таб «Розділи» деталей книги; один ChapterRow для обох місць |
| BookmarkDialog | keep | діалог (потрібен ввід нотатки); один патерн — не шит |
| Блок «Щось коротке» (SHORT) | keep | блок на «Слухати» (ADR-0015) |

## Деталі

### ТОП 100 — `Top100Screen`
- **Призначення.** Ранжований список книг джерел (4read) з реальними тривалостями.
- **Походження.** RESULT round 5 («КАТАЛОГ → ТОП 100»); спеки немає.
- **Критерій «працює».** Рядки BookRow з рангами, тривалості чесні (немає «00:00»), вхід з картки в Огляді.

### Виконавці / Автори — `PeopleScreen`, `PersonBooksScreen`
- **Призначення.** Списки персон джерела (читачі /readers.html, автори /avtors.html) і книги персони.
- **Походження.** RESULT round 5; спека 2026-08-15 каже «per-source browse — deferred until hydration lands» — фіча існує як продуктова поверхня без спек-зобов'язань.
- **Критерій «працює».** Список персон → сторінка книг персони; входи — окремі картки з іконкою в Огляді (режими перегляду, не фільтри).

### Сторінка жанру — `GenreScreen`
- **Призначення.** Повний список книг одного жанру (browse, не фільтр).
- **Походження.** RESULT round 3 (чіпи ЖАНРИ → «N книг у жанрі»); повноцінний жанровий браузер — поза обсягом спеки 2026-08-15.
- **Критерій «працює».** Вхід через тап по жанру в картці книги; список через спільний BookListScreen.

### Розділи (шит) — ChaptersSheet
- **Рішення.** Згортається в таб «Розділи» деталей книги — шит дублює таб, одна поверхня лишається.
- **Критерій «працює».** Таб «Розділи» рендерить ChapterRow (номер, назва, тривалість caption, play), поточна глава — акцент; невідома тривалість = порожньо.

### Діалог закладки — BookmarkDialog
- **Рішення.** Лишається діалогом (ввід нотатки); шит не вводити.
- **Критерій «працює».** Створення закладки з нотаткою + toast-відгук «Закладку додано на …» (плеєрні мікрополіші, #184).

### Блок «Щось коротке» — SHORT
- **Призначення.** Книги ≤ ~3 год для короткої сесії (ком'ютінг).
- **Походження.** `docs/wayfinder/prototype/personalized-listen.md` (прототип); увійшов у ListenComposer без окремої спеки.
- **Критерій «працює».** Блок лишається переставним/приховуваним як решта (ADR-0015); тривалість у мета-рядку картки.
