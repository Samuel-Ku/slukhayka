# Спайк T2 (#829): MTProto на Android — розмір і життєздатність

> Дата: 2026-09-16. Питання ADR-0050: **чи тримається шлях** «пристрій входить у
> Telegram акаунтом слухача й тягне файл напряму», і скільки це коштує APK.
> Вердикт — нижче; усі числа взяті з первинних джерел (реєстри пакетів і
> GitHub Releases) 2026-09-16, не з переказів.

## Що перевірено

### 1. Канонічний TDLib: чи є живі Android-збірки

- **Maven Central майже мертвий для TDLib.** Пошук дає рівно один артефакт —
  `ca.denisab85:tdlib`, остання версія **`1.8.8-20221107`, опублікована
  2022-11-12**. Це TDLib 1.8.8, тобто ~4 роки без оновлень; покладатися на
  нього як на єдине джерело не можна.
  (`search.maven.org/solrsearch/select?q=tdlib`)
- **Підтримувані prebuilt-збірки існують і свіжі.** GitHub-реліз
  `FaiBah/TDLibAndroidPrebuilt` **v1.8.67-d1085f9** опубліковано
  **2026-09-14** (дні тому), TDLib **1.8.67**:

  | Артефакт | Розмір |
  |---|---|
  | `tdlib.aar` (усі ABI) | 38,56 МБ |
  | `tdlib-Java-arm64-v8a.zip` | 9,93 МБ |
  | `tdlib-Java-x86_64.zip` | 9,76 МБ |
  | `tdlib-Java-armeabi-v7a.zip` | 8,76 МБ |
  | `tdlib-Java-x86.zip` | 10,44 МБ |
  | `tdlib-java-bundle.zip` (Java-біндинги) | 1,68 МБ |

- **Ціна в APK.** Застосунок уже шипить рівно два ABI — `arm64-v8a` і `x86_64`
  (`app/build.gradle.kts`, `ndk.abiFilters`). Отже нативна частина TDLib —
  **≈ 9,9 + 9,8 ≈ 19,7 МБ** нестисненого `.so` (у zip вони вже стиснені, тож
  порядок у APK той самий), плюс **≈ 1,7 МБ** Java-біндингів. Для APK, який
  зараз ~175 МБ у debug, це ~+11 %.

### 2. Альтернатива без нативної залежності: MTProto на Python під Chaquopy

У збірці **вже є Chaquopy + CPython 3.14** (`app/build.gradle.kts:618`) і на
ньому вже працює рушій yt-dlp (`app/src/main/python/ytdlp_probe.py`), тож
Python-рантайм у APK уже оплачений. Чистий Python-клієнт MTProto — це лише
колесо:

| Пакет | Версія | Колесо |
|---|---|---|
| Telethon | 1.45.0 | 785,3 КБ (`py3-none-any`) |
| Pyrogram | 2.0.106 | 3 489,9 КБ (`py3-none-any`) |

Джерело: PyPI JSON API (`pypi.org/pypi/Telethon/json`, `.../pyrogram/json`).

Але: обидва оголошують лише `requires_python >=3.5`, і **сумісність саме з
Python 3.14 на Android не перевірена** (це не факт, а ризик — потрібен
пробний запуск). Telethon без `cryptg` повільніший; `cryptg` — це знову
нативне розширення на кожен ABI.

## Вердикт

**Шлях тримається.** TDLib має свіжу (2026-09-14) підтримувану Android-збірку
TDLib 1.8.67 з per-ABI артефактами, і ціна для застосунку — **≈ 21 МБ**
нативної частини + біндингів на два вже наявні ABI, тобто ~11 % APK. Це
прийнятно, і це канонічний шлях ADR-0050.

**Рішення щодо джерела залежності.** Maven Central використовувати **не можна**
(1.8.8 з 2022). Prebuilt GitHub-реліз — варіант, але це supply-chain-рішення:
його треба або підключити як `flatDir`/`libs` AAR із зафіксованою версією в
репозиторії, або збирати TDLib у CI. **Остаточний вибір джерела — за
мейнтейнером**; я не тягнув артефакт у збірку без цього рішення.

**Python-варіант — не обрано.** Він дешевший за артефактом (0,8 МБ), але
додає неперевірений ризик сумісності з 3.14 і повільніший MTProto; тримаємо
його як резерв, якщо нативна збірка не заведеться.

## Що лишається перевірити на пристрої (до T3)

Пристрій підключено (`adb devices` → `2e7073f4`, OnePlus 8 Pro, Android 14).
Спайк-збірка має показати:
1. логін акаунтом слухача і збереження сесії між запусками;
2. читання повідомлення з групи `-1004476157917`, тема `573`;
3. розмір APK і поведінку під обмеженнями Android (фон, Doze);
4. жодного блокування з боку Telegram під час нормального використання.
