# Реліз 1.3: README та актуальні скріншоти

## Мета

Підготувати публічну сторінку проєкту до релізу 1.3: показати актуальний
інтерфейс застосунку на реальному OnePlus і коротко, просто та чесно пояснити,
що це за програма і що вона вміє.

## Позиціонування

README говорить від першої особи. «Слухайка» — особистий проєкт автора,
створений із цікавості та для власного користування. У програмі вже є всі
можливості, яких хотів автор. Проєкт доступний усім охочим для безкоштовного
завантаження й встановлення. Пропозиції вітаються, а подальші покращення
з'являтимуться, коли буде час і натхнення.

Текст не створює враження великої команди, комерційного продукту або
обов'язкового плану розвитку.

## Скріншоти

Основна галерея містить п'ять актуальних вертикальних скріншотів із OnePlus 8
Pro та використовує поточні дані медіатеки як реальну демонстрацію:

1. «Слухати» — головний екран із продовженням прослуховування.
2. «Огляд» — каталог і добірки.
3. «Медіатека» — книги користувача.
4. Сторінка книги — опис, джерела й доступні дії.
5. Плеєр — поточний розділ і керування відтворенням.

Якщо таймер сну або вибір швидкості виглядають виразно й не дублюють основні
кадри, їх можна додати другим коротким рядом. Системні сповіщення, клавіатура,
панелі налагодження та випадкові приватні дані в кадр не потрапляють. Файли
зберігаються оптимізованими для README, але без зміни самого інтерфейсу.

## Структура README

README зберігає короткий заголовок, посилання на Releases, ліцензію,
встановлення та інструкцію зі збірки. Вступ і розділ можливостей спрощуються.
Перелік функцій коротко охоплює:

- каталог українських аудіокниг із кількох джерел;
- медіатеку, пошук, серії та добірки;
- відтворення з пам'яттю позиції та розумним поверненням після паузи;
- регулювання швидкості, таймер сну, закладки й віджет;
- завантаження книг для прослуховування без інтернету;
- різні начитки та джерела однієї книги;
- оцінки й відгуки слухачів;
- темну тему та налаштування приватного мережевого маршруту.

Складні архітектурні подробиці й довгі пояснення внутрішніх механізмів не
виносяться в основний опис. Важлива інформація про анонімний профіль і код
відновлення лишається, але стисло.

## Версія та перевірка

`versionName` змінюється з `1.2` на `1.3`, а `versionCode` — з `3` на `4`.
README посилається на `slukhayka-v1.3.apk` і відповідний SHA-256 файл.

Перед завершенням:

- збирається актуальний APK;
- APK встановлюється на підключений OnePlus;
- перевіряється запуск і навігація ключовими екранами;
- перевіряються розміри та читабельність скріншотів;
- виконується релевантна Gradle-перевірка;
- перевіряється diff, щоб релізні зміни не зачепили сторонні файли.
