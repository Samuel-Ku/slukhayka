# Голос Слухайки (tone of voice)

> Канонічний зразок тону — фінальний пост про v1.3 у кінці файлу.
> Цей файл — інструкція для людей і агентів: будь-який текст, що виходить
> із репозиторію назовні (README, релізні нотатки, пости, відповіді в
> issues), звучить голосом автора.

## Хто говорить

Автор робив програму **для себе**. Він не маркетолог і не продає. Тон —
спокійний, особистий, трохи самоіронний. «Я зробив, мені подобається,
користуйтесь якщо хочете» — а не «ми раді презентувати революційний…».

## Правила

1. **Без пафосу й маркетингу.** Заборонені слова: «революційний», «найкращий»,
   «презентуємо», «потужний», «дивовижний». Перевірка: якщо фраза пахне
   рекламою — переписати сухіше.
2. **Короткі речення, прості слова.** Одне речення — одна думка. Без канцеляріту
   («здійснювати прослуховування» → «слухати»).
3. **Чесність про недороблене.** Якщо щось ще сирувате — так і сказати
   («інтерфейс ще не весь розкладений як треба»). Чесний стан > красива
   обгортка (це той самий принцип, що й в ADR-0014 для даних).
4. **Особистий погляд замість узагальнень.** «Робив для себе, тому там усе,
   що я хотів бачити» — а не «додаток задовольняє потреби користувачів».
5. **Усмішки доречні лише в неформальних текстах** (пости, P.S., відповіді
   людям): «:)» — так; емодзі-стрічки — ні. У README й релізних нотатках —
   без усмішок, але тепло.
6. **Українська мова**, жива, без суржику й без русизмів-кальок.
7. **P.S. у постах** — коротке, людське, із запрошенням писати.

## Структура соцмедіа-посту

1. Один абзац контексту: що це і навіщо («робив для себе…»).
2. Що нового — переліком у одному-двох абзацах, найважливіше першим.
3. Рядок про open source + посилання на релізи.
4. P.S.: працюю далі / пишіть, поділюся :)

## Інші поверхи

- **Релізні нотатки** (`docs/releases/*`): структура канону v1.2/v1.3 —
  «Що нового» смисловими блоками з номерами специфікацій у дужках, чесний
  розділ «що не увійшло», інструкція оновлення, підпис/ключ, «технічно для
  мейнтейнера». Людський текст, не переказ комітів.
- **README**: риски-фічі від другої особи однини («ти»), кожна риска —
  конкретна поведінка, не прикметники.
- **Коміти**: conventional prefix + українська тема, щільно, зі змістом
  («feat(reviews): #277 t3 блок «Відгуки» … — картки, форма, видалення за
  підтвердженням»).

>
> З того часу викотив величезне оновлення (v1.3). Головне нове - трохи краще

> рекомендації («схожі цикли» і персональні добірки), приватність мережі -
> трафік можна пустити через Tor або проксі одним перемикачем і виправив купу
> дрібних багів.
>
