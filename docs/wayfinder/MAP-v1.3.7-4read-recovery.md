## Gate 1.3.7 — чекліст пристрою (без download-recovery)

1. CI зелений: `testDebugUnitTest` + Kover gate + eval gate + accessibility
   API 35 (включно з `WorkSourceFkRegressionTest`).

   сторінка у вбудованому WebView → Cloudflare → аудіо захоплено →
   повернення в Player на той самий Chapter і позицію.

4. Мертве аудіо після recovery **не** оголошується успіхом.
5. Рекомендована книга з прямим Source стартує без браузера
   (LOCAL → DIRECT → UNKNOWN → BROWSER, ~10 с).
6. Блок «Джерела»: порядок = координатор, «Потрібен браузер» + TalkBack,
   рядки неклікабельні.

8. Той самий сценарій працює з вимкненим Firebase.
9. Тап «Сни» не крашить (#388 регресія).

  нових фіч у main, щоб не роздувати злиття.
