# #1236 — Web: рейл і список із деталями за спільною картою

**Дата:** 2026-10-25 · **База:** `origin/main 980929ad` · **Гілка:** `t1236-auto-1236`
**Браузер:** Google Chrome 155.0.8059.79 (headless, CDP), Linux-воркер `192.168.2.223`.

## Що виміряно

`scripts/web-layout-probe.mjs --widths 411,599,600,839,840,1280` на зібраному
бандлі цієї смуги (ширина вікна, 900 px висоти). Числа — з реального layout
engine, не з jsdom:

```text
width  layout    column  col width  gutter  source    tracks    track widths       overflow
------ --------- ------- ---------- ------- --------- --------- ------------------ ---------
411    compact   640px   411px      16px    document  1 (grid)  379px              no
599    compact   640px   599px      16px    document  1 (grid)  567px              no
600    expanded  1040px  600px      24px    document  1 (grid)  464px              no
839    expanded  1040px  839px      24px    document  2 (grid)  343.5px + 343.5px  no
840    expanded  1040px  840px      24px    document  2 (grid)  344px + 344px      no
1280   expanded  1040px  1040px     24px    document  2 (grid)  444px + 444px      no
```

599 → compact, 600 → expanded; 840 не змінює сітку списку (це друга лінія
плеєра), але саме на ній у кадрах з'являється права панель плеєра й провідна
колонка міні-плеєра.

`<audio>`, а не статичну картинку. CSS, компоненти й розкладка — зібраний
бандл цієї гілки.

## Межі перевірки

- **Safari PWA не перевірено:** на цьому Linux-воркері немає Safari/WebKit і
  iOS-пристрою. Це лишається недоведеним у звіті тікета, а не «зеленим».
- Кадри знято на headless Chromium; інтерактивність (клік по рядку, Back,
  фокус, scroll) додатково піниться jsdom-тестами
  `web/src/ui/appLayoutPanes.test.tsx`, а не самими кадрами.
- `scripts/web-layout-probe.mjs` міряє список у `.surface`; рейл і панелі
  видно на кадрах, окремих числових полів для них щуп не має.
