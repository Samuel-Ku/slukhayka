# Прототип: Liquid Glass / Glassmorphism

Тут лежить **одноразовий прототип**, який відповідає на одне питання:

> Як би Слухайка виглядала у стилі Liquid Glass / glassmorphism?

Це не продакшн-код і не дизайн-система. Це три грубі макети, які треба
подивитися, обрати один (або вкрасти шматки з кожного) і викинути решту.

## Як відкрити

Найпростіше — подвійним кліком:

```
web/prototype/liquid-glass.html
```

Або через dev-сервер вебзастосунку:

```bash
cd web && npm run dev
# http://localhost:5173/prototype/liquid-glass.html
```

Жодних залежностей, збірки чи інсталяції не потрібно.

## Liquid Glass — це матеріал, а не фільтр

Найважливіше, що дає цей прототип: різницю між **Liquid Glass** і
**glassmorphism** видно поруч, на одному макеті.

| | Glassmorphism (2020) | Liquid Glass (2025) |
|---|---|---|
| Що робить із фоном | розмиває (`backdrop-filter: blur()`) | **згинає** (displacement mapping) |
| Світло | статична рамка `1px` | спекулярна грань + спекуляр, що зсувається |
| Де живе | будь-де, найчастіше на всьому | лише на плаваючому шарі |
| У CSS | чотири властивості | `feDisplacementMap` + `blur` + маска + тіні |

«Genuine refraction in a browser needs displacement mapping or a shader, not
`backdrop-filter`» — тому тут карта зсувів рахується в canvas: SDF
заокругленого прямокутника дає лінзу зі схилом біля грані, canvas віддає її в
SVG-фільтр як `feImage` (data-URI), а `feDisplacementMap` тягне крізь неї
backdrop. Підхід запозичено з [shuding/liquid-glass](https://github.com/shuding/liquid-glass);
фільтри кешуються за розміром панелі.

Перемикач **Liquid Glass ⟷ Glassmorphism** у тулбарі показує обидва матеріали
на одному й тому самому макеті — щоб різниця була видна, а не описана.

## Що всередині

П'ять реальних екранів застосунку — **Слухати · Огляд · Медіатека · Книга ·
Плеєр** — у трьох радикально різних системах скла. Копірайт і обкладинки взяті
з `docs/screenshots/`, тож варіанти судяться в оточенні застосунку, а не у
вакуумі.

| Ключ | Назва | Що це |
|---|---|---|
| `a` | Liquid Glass | рефракція + спекуляр; скло **лише на плаваючому шарі** (навігація, шапка, пошук, міні-плеєр, лоток плеєра), а контент — суцільні поверхні |
| `b` | Frosted Paper | світла «паперова» тема, скло майже без тону (`blur(12px)`), волосяні лінії, **плоскі** списки без карток, навігація врівень з низом |
| `c` | Prismatic Bento | дуже темна база, `blur(34px) saturate(220%) contrast(112%)`, веселкова хроматична грань, амбровий bloom, **сітка-бенто** замість рейок, док-навігація |

Варіанти розходяться не кольором, а структурою: різна навігація, різна
ієрархія головного екрана (hero-картка → компактна стрічка → бенто), різні
поверхні під контентом.

## Перемикачі

Усе живе в URL, тож посиланням можна ділитися:

```
?variant=a|b|c        система скла
?material=lg|gm       (лише для A) Liquid Glass або Glassmorphism
?transparency=reduced те саме, що HIG Reduce Transparency
?screen=listen|explore|library|book|player
?mode=single|all      один великий макет або всі п'ять поруч
```

- Стрілки `←` / `→` на клавіатурі — наступний/попередній варіант.
- Плаваюча пігулка внизу по центру — те саме мишкою.
- Верхні вкладки — екран, режим, матеріал, прозорість.

## Три речі, які прототип навмисно перевіряє

1. **Скло — для шару, що плаває над контентом, не для контенту.** У варіанті A
   картки, рейки й тексти суцільні; скло лише на хромі. Увімкніть
   `Glassmorphism` — і побачите, чому: тіло тексту на склі над строкатою
   обкладинкою перестає читатися. Apple на це публічно наступала й додала
   контролі непрозорості в 26.1.
2. **Стриманість читається як навмисність.** Скло на склі на склі — це демка.
3. **Reduce Transparency — не крайовий випадок.** Перемикач поруч із рештою:
   усе скло стає суцільним, рефракція й blur вимикаються.

## Чого тут свідомо немає

Немає тестів, обробки помилок, продакшн-абстракцій і персистентності. Стан
живе в пам'яті й у query-параметрах. Файл не імпортує нічого з `web/src` і не
впливає на жоден продакшн-модуль. Справжньої хроматичної дисперсії теж немає:
це вже фрагментний шейдер, а не SVG-фільтр.

Коли варіант переможе — його треба переписати як слід (Compose-тема для
Android, CSS для вебу), а цей каталог лишити як первинне джерело на окремій
гілці, не в `main`.
